# 社区工作台界面规范

采用代码托管平台式的信息层级：浅灰分区、白色内容、细边框、紧凑导航、绿色主要操作和蓝色链接。不使用 GitHub 标志，不复制其页面或引入外部图标服务。

## 共用规则

- `styles/community-theme.css` 通过 `html[data-site-mode="community"]` 覆盖语义变量；原阅读器主题不受此根主题影响。支持浅色、深色和跟随系统，原生表单同步 color-scheme。
- 普通正文 14px，辅助内容通常 12px；表单/按钮圆角 6px，面板 8px。优先使用现有 Button、Input、Card、Modal，避免另造一套颜色。
- 主按钮为绿色，链接与键盘焦点为蓝色，危险/警告/成功保留语义色。主要文字及按钮配色有对比度测试，不能以降低不透明度替代可读的次级文字。
- 悬停以边框、背景变化为主，减少大阴影、悬浮位移及大面积渐变；尊重减少动态效果设置。
- 游戏场景、人物、武器、稀有度、桌宠插画与新闻来源标识保留原配色。只统一其外围页面和常用操作区，不把此改版当成玩法更新。

## 导航与小屏

首页采用日常工作台表达；导航使用本站内置的线性 SVG 图标。全站已有的功能开关和权限判断保留。

社区页头的「全部栏目」可按名称及简介搜索，支持空结果反馈、键盘焦点圈定、Esc 关闭、返回触发按钮及跳转后关闭；切换账号关闭目录。开发协作、审核台及资讯台仍按原权限展示，不授予任何实际成员新角色。

手机底栏使用细边框浅色样式，六入口可收缩；完整目录可直接进入小游戏、工具、排行榜和账号安全，不依赖首页。会话页仍使用 58px 页头，首页独有快捷入口不会挤占聊天输入区。

## 交付边界

### 主题偏好

社区、工具及游戏页头都有主题选择器，窄屏保留图标式原生选择控件。默认跟随系统；选择只保存在当前浏览器的 `webfish:appearance:v1`，不上传、不计费，也不按账号同步。支持其他标签页修改及系统配色变化，手动选择优先于系统。

同源 `workspace-theme.js` 在样式和 React 前读取偏好，避免已选深色的首次绘制闪白，不放宽 CSP。浏览器拒绝存储时仍可切换，本次页面会显示「仅本次生效」。主题切换不重新挂载路由，不清空工具草稿或更改对局状态；选择器里的 Esc 不触发游戏遮罩。游戏场景、像素角色、稀有度和用户图片保留，不采用整页反色滤镜。

本次仅前端。没有后端、接口协议、数据库迁移、经济奖励或账号权限变更；发布只替换 API/Web 镜像，生产配置仅改 IMAGE_TAG。实际发布版本、备份、测试与回滚记录另见当次发布文档，本文不代表已经部署。
