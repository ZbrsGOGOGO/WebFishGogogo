## 第二阶段已上线

- **我的工作台 `/me`**：先展示保存的身份、佩戴称号、真实余额和今日收支，再展示成长、权益、常用与最近入口。个人资料编辑器默认折叠，公开展示入口进入隐私设置；未保存的头像不混入已保存档案。
- **资料读取与会话边界**：完整资料读取失败时编辑和保存都禁用，允许明确重试；快速重复保存受锁保护。切号、同账号重新登录与卸载后的旧请求/回执不能覆盖新会话。重新登录后恢复原计时节奏，不重复认可旧会话时间。
- **成长档案 `/achievements`**：完整保留真实 44 项目录，按日常与共创、工位绿植、游戏与挑战、九层妖塔、开发协作五类组织。分类、解锁状态和名称/称号搜索联动，区分已解锁、达标待同步和进行中；缺少服务端进度时显示未读取，不补造零进度。
- **称号展示**：当前佩戴与收藏目录分开，换称号先明确确认；保留原幂等键、版本检查、隐私与维护只读限制，不自动解锁、领奖或佩戴。
- **成长与期权摘要**：展示六级真实阈值、下一等级差额、今日额度与折叠规则。权益区分有效、待生效、过期和未知状态，截止时间明确使用北京时间；仅展示已核验有效支持金额、月数和笔数，赠送/作废不混入有效金额，缺失不伪装为零。
- **管理员支持台账**：页面默认不挂载或读取台账，管理员明确展开后才读取。折叠保留草稿与未知提交结果；权限丢失或会话变化清除私有状态。读取失败、空列表和有效/毛额分别说明；未知财务回执保留原操作标识并阻止其他财务写入，不自动重试。
- **公开同事档案 `/users/:id`**：身份、简介、荣誉与好友互动统一层次和布局，长名/简介窄屏换行、操作入口有足够触控面积。只使用对当前访问者开放的资料；并行读取只接受最新结果，受限的新投影不能被旧公开投影覆盖，不混入本人钱包或私人支持汇总。

办公币、XP 认可、每日上限、成就目录与解锁规则、赠送期限、月度支持授予、游戏存档与排行榜均未改变。没有新增真实付费服务、账号角色或权限，没有读取/回写新的开发协作反馈。用户暂停的 Palm AI 依赖和接口文件仍未提交或部署。
