# 办公室乐斗：等级、PVE/PVP 与技能图鉴 V1

## 1. 系统边界

乐斗角色由五个相互独立但可组合的模块构成：

1. **共享等级**：PVE 与 PVP 获得的战斗经验进入同一等级，最高 Lv.60。
2. **共享装备**：六件装备同时用于两种模式；PVE 计算全部强化增量，PVP 只计算强化增量的 60%。
3. **PVE 技能树**：只在 NPC 项目挑战中生效，使用独立 PVE 技能点。
4. **PVP 技能树**：只在好友对战中生效，使用独立 PVP 技能点。
5. **模式战力快照**：服务端分别计算 PVE/PVP 五维属性和战力，页面不自行推导。

这样拆分后，等级、装备、技能、PVE、PVP 可以分别调整，且不会修改玩家已有资产。

## 2. 等级成长

- 等级范围：Lv.1～Lv.60。
- 从当前等级升到下一级所需经验：`80 + 20 × 当前等级`。
- 满级累计经验：40,120。
- PVE 奖励战：胜利 30 经验，失败 15 经验；三档难度和帮派加成可继续修正。
- PVP 奖励战：胜利 25 经验，失败 12 经验。
- 练习赛：0 体力、0 经验、0 货币、0 掉落。

关键解锁：

| 等级 | 解锁内容 |
|---|---|
| Lv.1 | 初始职业、标准装备、第一项 PVE 技能 |
| Lv.4 | 第二项 PVE 技能 |
| Lv.5 | 第一项 PVP 技能及首个 PVP 技能点 |
| Lv.8 | 第三项 PVE 技能 |
| Lv.9 | 第二项 PVP 技能 |
| Lv.10 | 精工装备 |
| Lv.13 | 第三项 PVP 技能 |
| Lv.20 | 专业装备 |
| Lv.30 | 卓越装备 |
| Lv.40 | 代表作装备 |
| Lv.60 | 等级上限 |

技能点规则：

- PVE：Lv.1 获得 1 点，之后每 4 级增加 1 点，最多 15 点。
- PVP：Lv.5 获得 1 点，之后每 4 级增加 1 点，Lv.60 再增加 1 点，最多 15 点。
- 两种技能点互不占用。单项技能最高 Lv.5。
- 技能升级消耗：100 / 300 / 700 / 1,500 / 3,000 办公币。

## 3. PVE 与 PVP 的明确区别

| 规则 | PVE 项目挑战 | PVP 好友对战 |
|---|---|---|
| 对手 | 服务端生成的 NPC 项目组 | 满足条件且允许挑战的好友 |
| 生效技能 | 仅 PVE 技能 | 仅 PVP 技能 |
| 装备强化 | 强化增量计入 100% | 强化增量计入 60% |
| 胜利基础奖励 | 30 经验、80 办公币、可掉装备 | 25 经验、120 办公币、可掉装备 |
| 失败基础奖励 | 15 经验、40 办公币 | 12 经验、60 办公币 |
| 每日奖励上限 | 14 场 | 5 场 |
| 特殊限制 | 三档难度；可获得帮派 PVE 经验加成 | 好友关系满 24 小时；同一好友每日 1 次奖励 |
| 练习赛 | 可用，0 消耗、0 奖励 | 可用，0 消耗、0 奖励 |

两种战力沿用同一公式：

`战力 = 四舍五入(活力×0.34 + 执行×3.20 + 抗压×2.50 + 反应×1.80 + 洞察×1.20)`

差异来自装备强化折算和模式专属技能，不额外使用隐藏倍率。

## 5. 后续平衡约束

- 同等级、同品质、相近强化的五职业 PVP 胜率目标为 48%～52%。
- 任一职业连续两周低于 46% 或高于 54% 时，只调整该职业技能系数，不回收装备、不重置技能等级。
- PVE 通关效率以相同培养投入的中位耗时比较，职业间差距控制在 15% 内。
- PVE 办公币主要支撑装备强化；PVP 办公币主要补充技能升级，避免玩家被迫只玩一种模式。
- 所有战力、奖励和技能升级以服务端数据为准，客户端只负责展示。
