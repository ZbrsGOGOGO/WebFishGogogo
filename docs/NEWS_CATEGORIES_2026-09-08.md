# 分类资讯与平台榜单入口

## 三个页面

- `/news`：按综合、国内、国际、社会、财经、文娱、体育浏览 RSS 新闻标题。分类选择使用 URL 参数，支持浏览器前进/后退。
- `/news/trending`：综合社交、视频文娱、科技知识三组官方入口。包括微博、知乎、百度、哔哩哔哩、抖音、豆瓣电影、GitHub Trending、Hacker News。
- `/news/editorial`：保留原人工编辑导读、职业/主题筛选和主动选择的资讯偏好。详情 `/news/:id`、管理 `/news/admin` 及其权限边界不变。

首页补充分类新闻与榜单入口，手机无需展开桌面侧栏也能找到；不占用底部社交导航。新闻仍需登录，不扩大管理权限。

## 真实 RSS 数据

仅使用[中国新闻网官方 RSS 目录](https://www.chinanews.com.cn/rss/index.shtml)中的 `importnews.xml`、`china.xml`、`world.xml`、`society.xml`、`finance.xml`、`culture.xml`、`sports.xml`。保存标题、官方 HTTPS 原文链接、原始发布时间与分类，不采集新闻正文、图片、音视频或生成冒充原文的内容。

原新华政治 RSS 在核验时缺少必需的发布时间，未用抓取时间冒充发布时间，本版移出有效源清单。原库历史来源仍有兼容映射。

规则：

- 保留北京时间每天 08:00 的新闻快照；每天最多完成一次，部署时已完成的旧版当日快照允许升级一次。
- 每类最多 8 条，目前 7 类最多 56 条；总上限为 60，分类不是热门排名。
- 按标题和原文 URL 去重，专门分类优先于综合分类；原始发布时间必须在最近 72 小时内，拒绝明显的未来时间。
- 最多 3 个并行 RSS 请求，每个 8 秒超时，流式读取最多 2 MB，仅接受 XML，不自动跟随重定向。文章链接校验发布者域名并规范为 HTTPS。
- 任一来源未返回有效的新鲜标题，整批不替换旧快照；保留旧数据和原更新日期，等待 5 分钟定时检查重试。过期内容不会无限保留在界面上。
- 用 `chinanews-v2-*` 来源键识别新分类快照，不加迁移。拉取发生在事务外，最终替换在同一事务内完成；租约含随机标识与开始时间校验，过期工作不能覆盖新工作。

API 保留 `GET /api/v1/news/headlines/today` 的既有字段，增加 `categories: [{id,label,count}]` 与每条标题的 `category`。新前端兼容旧响应，将无分类数据归入综合；读取失败明确提供重试，不伪装成“今天没有新闻”。

## 平台榜单的明确限制

本版八个平台均为官方外链导航，不在站内同步实时榜单条目，不展示捏造的排名、热度、抓取时间或标题。链接打开新窗口并带 `noopener noreferrer nofollow`，不用 iframe，也不自动加载第三方追踪资源。

微博核验时要求访客验证，知乎核验时存在拒绝/验证限制；不绕过登录、反爬或付费，不添加用户未授权的接口凭据或服务。其他入口即使可以公开打开，也不因此声称获得自动转载或聚合授权。后续如接入站内榜单，需要另行核验可用来源、接口权限、缓存与原始排名含义。

人工编辑导读仍遵循[编辑与来源策略](NEWS_EDITORIAL_POLICY_V1.md)的来源核验和复核流程，RSS 标题索引不是绕过人工发布审核的入口。本次不修改人工稿件状态、账号角色、后台开关或用户偏好。
