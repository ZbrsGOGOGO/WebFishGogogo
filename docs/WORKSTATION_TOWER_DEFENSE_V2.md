# 工位塔防 V2：办公用品合成

本文件保留 V2 历史约定。下一版两回合难度改造见 [V3 范围](./WORKSTATION_TOWER_DEFENSE_V3.md)，不将后续实现反写为 V2 原有能力。

2026-09-07 经站点所有者确认的首版范围。本文是实现与验收约定；已上线版本、验收证据和后续边界见 [本次发布记录](./RELEASE_2026-09-07_TOWER_V2.md)。

## 本期交付

把“直接花钱买塔、花钱升级”改为一局独立的经营与合成循环：

绿植产金币 → 商店购入零件 → 同名同阶三合一 → 合成塔部署 → 自动防守 → 投资绿植或补强阵容。

- 保留固定工位路线、九个塔位，以及始终唯一的工位守卫。角色默认站在能攻击敌人的位置；不操作角色也有基础输出，移动和专注脉冲用于补强。
- 商店提供办公用品的一阶零件。开局保底同名零件及足够启动金币，允许先购置绿植，再完成第一座塔。初次防守仍由玩家主动开始。
- 背包内三个同名同阶物品合成一个高阶物品；一阶不可部署，二阶可部署，三阶封顶。场上塔参与合成时保留塔位，不能重复结算或凭空增值。
- 五条塔线分别为订书机、咖啡机、打印机、转椅、碎纸机。以单体、减速、范围、击退及特殊伤害形成区别；升阶外形和效果应可辨认。
- 背包满、余额不足、重复购买、无效塔位、出售与合成失败必须给出原因，不扣款、不吞物品，不允许负金币。
- 绿植的产币随有效战斗时间推进。准备期、波间、暂停、失焦、胜负结算后不产币，不能靠停留在准备页无限积攒。
- 三波短局以约 1–3 分钟有效战斗为目标；不计玩家整理阵容与暂停时间。至少一套不移动角色的基础阵容应可通关，同时允许继续经营与合成高阶塔。
- 用原生 SVG、CSS 和页面组件呈现办公用品外形、射程、攻击与合成反馈。桌面与 390 像素手机宽度均应能完成购物、合成、部署、技能和暂停。

## 数据与范围边界

- 本期仍是纯浏览器单局。局内金币不是社区办公币，不扣农场经验、不发账号资产、不创建排行榜成绩。
- 只保存 V2 本机最高分。V1 的 `momo.workstation-tower-defense.settings.v1` 原样保留，不读取、不删除、不把旧分数混入新规则。
- 不保存当前阵容或对局进度。离开、刷新或关闭网页不会产生离线战利品；页面须明确提示。
- 旧乐斗代码、数据表与本机存档保持不变。不恢复旧乐斗接口，也不借用旧乐斗奖励流水。
- 离线收益、跨设备存档、多职业天赋、账号级抽卡、付费和部门协作 Boss 属于后续阶段。需要独立服务端校验、结算幂等与授权，不因本期上线被标记为全部完成。

## 验证要求

1. 引擎验证绿植产币与暂停边界、保底开局、商店补货、三合一递归、已部署塔合成、出售守恒、满包及余额不足、不合法/重复操作、胜负与重开。
2. 确定性模拟验证三波时长、英雄默认输出、不操纵角色的可通关阵容；多种商店种子与操作序列检查金币、容量和等级等不变量。
3. 页面测试验证唯一角色、购物与背包、部署和卖出、键盘与触屏、暂停失焦、仅保存本机最高分、无账号资产请求。
4. Firefox 实际页面验证桌面与手机布局、至少一条完整购物→合成→部署→防守路径，并检查浏览器错误。
5. 全仓回归、类型检查与生产构建通过后，沿用当前 Compose 完成备份、恢复验证、应用发布和线上检查。不得重建数据服务、回退数据库或扩大成员权限。
