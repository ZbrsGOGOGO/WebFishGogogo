# 你画我猜 / 谁是卧底：办公生活词库第二版

本轮是现有小游戏的低风险词库扩充，候选版本 `office-life-20260909-v2`，是否已部署以发布记录为准。

## 已实现范围

- 你画我猜从 8 词扩到 64 词：原 8 词全部保留，追加办公设备、文具、家具、日用物品、交通工具和食物等 56 词。新增每词都有不同的服务器线稿，单人练习不会遇到没有图的答案，也不把答案文字画在图上。
- 谁是卧底从 12 对扩到 48 对：追加 36 对相近的办公/生活事物，各配两条不直接念出答案的系统搭档描述。不使用同事姓名、真实用户信息或群体标签。
- 单人系统搭档与真人建房共用这套私有后端词库。画词只向当轮画手展示；卧底只向本人展示其词语，游戏结束前不公开角色。
- 现有抽题和系统搭档均按实际数组长度/持久化索引取值，没有 8/12 硬编码取模。无须修改抽题核心、计分、每日排行、办公币结算或账号数据。

## 旧局兼容

词库数组下标就是已有 JSON 存档使用的稳定 `wordIndex` / `pairIndex`。本次只在末尾追加，绝不排序、插入或重编号。旧画词 0–7 的标题与所有坐标、旧卧底 0–11 的两侧词语与描述都原样保留；测试使用上一已提交版本的 SHA-256 指纹检查。

已有绘画局在读取、重载和猜词时继续解释同一旧索引；新回合才重新抽题，原 `usedWords` 仍参与不重复抽取。已有卧底局保存的角色/词语不变，后续轮次系统描述仍通过旧 `pairIndex` 对应到原描述。没有删除、迁移、重置或重新播种数据库。

版本字符串仅用于维护记录，不作为随机种子，不回填已有局，也不导出全部词库给客户端。今后仍必须追加；若需删除或重排，必须先另做带版本的完整存档兼容设计。

## 不是本轮上线的功能

这不是异步画墙、多卧底玩法、每日主题、评分重做、玩家自建词库或大策划全量完成。这些需要单独的权限、内容治理、界面和结算设计，不能将“词条变多”记成整个提案已完成。

## 定向验证

- 64 / 48 精确数量与唯一性，原 8 / 12 完整内容指纹不变，所有线稿独立且满足画板坐标/笔画边界；多个练习板不能修改共享模板。
- 使用普通创建种子覆盖全部 64 画词和 48 词对，不给测试注资或注入分数。64 种单人绘画均走完三轮正常猜词；2–8 人绘画房轮换、不重复与隐私；3–8 人卧底维持单卧底及旧计分规则。
- 合成旧格式 JSON 的反序列化、投影、正常猜词，以及下一轮系统描述兼容。不冒充读取了真实用户存档或生产 PostgreSQL 锁验收。
- 定向引擎与服务回归、类型检查；真实画板的识别度和窄屏观感仍由最终浏览器验收补充，不以纯数据边界测试代替视觉验收。
