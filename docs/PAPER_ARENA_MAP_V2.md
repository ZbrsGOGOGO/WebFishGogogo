# Paper 联机地图：原地标、扩展外环与权威几何

## 来源和可重复核验

原 `ArenaBuilder.ts` 源自已审查的 Ballpoint Breach / Apache-2.0，锁定上游提交 `96290df3fba1c2b64abac684510155d916117903`，现有许可证/NOTICE 保留于 `third_party/ballpoint-breach`。新增元数据是原几何的代码衍生，不来自截图、外部地图或生成图片。

`paper-arena-original.generated.json` 保留原构建结果的 **316 个实体 AABB、388 个射线模型 AABB、36 个旧导航标记和 22 个旧出生标记**，另有补给/钩索标记与原安全出生点。浮点 bounds 不四舍五入；仅将 JSON 不区分的 `-0` 规范成 `0`。记录原 Builder 的 SHA256。

仓库根目录运行：

```sh
node packages/frontend/scripts/extract-paper-arena-map.mjs --check
```

工具在无 WebGL/浏览器的 CPU 环境运行原 `buildArena()` + `syncColliderBounds()`，逐值比较快照。`--print` 只向 stdout 输出候选快照，**不会自动覆盖仓库**，变更必须检查。THREE 只存在于 frontend 提取器及视觉适配器，不进入后端共享几何运行时。

## 实际地形

`PAPER_ARENA_MAP.id = office-expanded-v2`。平面范围 **96 × 102**：`x [-48,48]`、`z [-58,44]`，地面顶面 `y=0`。所有 `{x,y,z,w,h,d}` 的 y 是 **盒子中心**；玩家 y 是脚底。

原脚手架、三栋建筑及上层、楼梯、橙色长桥、后部栈桥、吊机、管架、箱子和纸飞机的位置均未移动。联机视觉适配器只移除 `arena-ground-and-perimeter` 原五盒，并按共享 `extensionBoxes` 添加：

- 新完整地板与四面外围墙；墙内表面恰在规定边界。
- 北面四个高货箱岛、三个矮掩体。
- 东西各四个货箱岛、三个交错矮掩体。
- 南面四个矮货箱岛、三个高交错掩体。

合计 **33 个新增可见盒子**。不是只把地板放大；外环保留多米宽的连续通路，并有交错高低遮挡。每个新增 collider 都含原风格 material，前端必须真实渲染，不能出现权威服独有的隐形墙。原单机 Builder 与行为不修改。

## 实体、射击与装饰的区别

- `colliders` / `obstacles`：移动和立足实体；上下层/地下穿行按完整三维 y 判断，不把高架平台投影成地面禁区。
- `raycastBoxes`：原逐 mesh 射线 AABB + 新扩展盒。原门框强调、水箱、吊钩/吊索是只挡射线、没有原移动碰撞的模型，单独保留；不能仅拿移动 collider 判断子弹。
- 非盒状水箱、吊钩、旋转板材仍采用原模型 world AABB 的**保守射线近似**，不是逐三角形/孔洞精确射线。窗洞由原分开的窗台、立柱和上梁保留；木栅栏使用逐木板射线盒，不以整块移动 AABB 填死全部缝隙。
- 原纸飞机、细栏杆/斜撑是非交互装饰，不新增射击或人物碰撞。
- 原补给 `supply-1` 至 `supply-10` 在联机隐藏，其装饰底座/菱形也从射线集合剔除，未实现的补给不能显示成可用互动。
- 六个木栅栏在联机保持静态；不调用本地 `damageBreakable` 制造与服务器不同的破坏状态。

## 支撑、导航和出生

共享 `paperArenaMapBodyClear` 使用人物足底圆盘半径 0.38、身高 1.8 与真实 AABB 的三维碰撞；检查整个人物都在边界内。`paperArenaMapFloor(x,z,maxY,radius)` 取足底圆盘重叠的最高可支撑顶面，与原 `PhysicsWorld` 一致。站立移动额外 `allowStep=true`，可踏过脚底上方 0.46 内的台阶；空中/严格出生检查不能启用该宽限。

旧 36 个 waypoint 的边包含跨层直线，**仅作为来源记录，不能当作已验证可走路线**。新的 `getPaperArenaNavigation()` 为后端惰性构图：

- 地面和平台使用 1m 采样，楼梯补每个真实踏面中心及踏宽两側、入口/出口点。
- 靠建筑的楼梯中心可能碰到外墙；测试使用实际可通行外侧踏宽，不移动墙或虚构地板。
- 每条候选边按 0.08m 分段，反复检查足底支撑、头部空间和 0.46 步高，拒绝墙体穿越、跨层跳线或没有支撑的空洞。高落差不作为普通步行边。
- 仅保留最大双向连通区，供 AI A* 使用。当前 **10506 个节点、446 个楼梯/落脚节点**，本机首建约 **0.53 秒**，后续复用；前端视觉无需触发构图。
- 十组原楼梯均连通，脚手架各层、西楼顶、utility/office 屋顶、橙桥、后栈桥和 service catwalk 均有可达点。仅钩索才能到达的吊机顶或孤立高顶仍保留视觉/碰撞，但不虚构普通 AI 步行入口。
- `getPaperArenaSpawnPoints()` / `MAP.spawnPoints` 从原地面位置及四面外环筛选，使用 **0.65 半径严格空间检查**、真实地面支撑和导航邻近性；不是随机无约束点。动态安全距离、敌人位置和是否拥挤由权威引擎最终挑选。

## 验证

2026-09-09，新增 8 项地图测试及原 Builder 5 项回归 **13/13 通过**，约 4.12 秒；shared typecheck 通过。包括来源哈希与每个数值、一对一三维 AABB、原单机不变、实体/射线/装饰边界、上下层与头顶碰撞、十楼梯及各主平台连通、**每一条导航边重新碰撞/支撑复验**、严格有效出生点及四外环覆盖。

此记录只代表地图模块；最终角色移动/武器/联网、视觉适配和生产发布以总验收记录为准。
