## 使用方式与边界

社区、工具和游戏页头新增主题选择器：**跟随系统、浅色模式、深色模式**。手机使用太阳/月亮/显示器图标式原生选择控件。默认跟随系统，手动选择优先，并记住当前浏览器的偏好。

偏好仅保存到 `webfish:appearance:v1`，不上传、不按账号跨设备同步；支持其他标签页修改和系统配色实时变化。浏览器禁止保存时仍可切换，并显示「仅本次生效」。同源启动脚本在 React/样式之前设置背景，减少深色刷新闪白，没有放宽 CSP。

主要页面、表单、弹窗、聊天目录、工具、开发协作、成就、桌宠设置和游戏外围面板适配深色；保留游戏场景、角色、武器、稀有度、桌宠及用户图片原色，不使用整页反色滤镜。主题切换不重挂路由，不清空工具草稿；主题选择器中的 Esc 不触发游戏便签遮罩。详见[界面规范](INTERFACE_DESIGN.md)。
