新游戏不上传成绩、不发办公币、不进入正式奖励榜或全站游戏成就，也没有本站联网房间。局内预算、矿产、商店和原游戏成就是各自游戏数据；全站原有活跃成长规则不变。四子棋的同屏双人不是玩家建房，in ASCENT 是太空经营，不是平台跳跃。

### 实际修复的兼容与界面问题

- 四子棋开局改为 CSP 安全的外部事件和显式关闭对话框，不通过授予表单权限修复；胜者名字转义，保留原 AI 和胜负规则。
- 架构守关五组运行指标统一在可折叠滚动面板中，折叠同步不可访问状态，避免小窗指标覆盖整个场景。
- 麻将补上可用牌的键盘/辅助技术交互，受限牌不泄露隐藏牌面，沿用原配对条件。说明移到设置正常文档流，不覆盖底部得分与步数；opaque origin 下的路由与存储安全降级。
- Radius Raid 增加真正调用原开局/菜单逻辑的中文操作栏，不把“可加载标题”当作能开局；没有新增完整手机控制。
- in ASCENT 动态内联点击转换为外部数据事件，交易先验证实际支付库存，触控及失焦清理不重置资源；不启用商业化分支。

## 源码、许可与隔离

各款固定完整上游提交、保留修改后首选源码、许可和依赖署名；固定来源及逐款改动见[实验室说明](LOCAL_GAME_LAB.md)。Server Survival / c4 有独立机械构建脚本，Whatajong 分发完整独立 Web 源码、锁文件和自动后处理；Hextris / Radius Raid / in ASCENT 分发可读执行源码。主站锁文件和依赖未改变。

Hextris 以 **GPL-3.0-or-later** 独立程序运行，不混入 React bundle，提供完整首选源码与依赖来源；公共生命周期桥另以 MIT 授权。Whatajong 依赖完整署名包括 MIT、Apache、Unicode、ECMA 等实际文本。保留 WebP / SVG 的依据是固定仓库整体许可且未见相反声明，不冒充逐图作者认证；来源不清晰的音频、商业字体、营销图和 Twemoji 字体不发行。

所有运行资源本地自托管，广告、遥测、外传分数、原远端房间、商业化及不支持的文件分享入口移除或禁用。游戏 `sandbox` 仅 `allow-scripts`，不授予 same-origin、表单、弹窗、下载或顶层导航；消息只交换生命周期，校验当前窗口、来源及 nonce，不传账号、Cookie 或成绩。

Nginx 本批仅新增**六个确切实验室游戏文档**的 `SAMEORIGIN` / `frame-ancestors 'self'` 例外，既有遮司嵌入例外保留；站点外壳继续 `DENY` / `frame-ancestors 'none'`。六款游戏 `connect-src 'none'`，不使用脚本 `unsafe-inline` / `unsafe-eval`，缺失游戏文件返回 404，不伪装 SPA 脚本。来源链接在父页说明中显式新页查看，不替换游戏沙箱。
