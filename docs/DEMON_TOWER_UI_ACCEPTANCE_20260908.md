## 已复现问题与修复追踪

1. **手机固定底栏与自动滚入视口冲突。** 刷新后标准 WebDriver 点击回春术，按钮中心 y=731 被底部页签覆盖，返回 ElementClickIntercepted。v3 仅增加 `scroll-margin-block: 20px 110px`，真实原路径重试仍失败：Firefox 对部分已在视口的按钮不重新滚动。v4 改为手机首次进入/恢复遭遇时自动呈现完整回合操作区，并对键盘聚焦避让底栏；明确使用 instant 避免全局 smooth 导致控件移动。**v4 原路径真实通过**：390宽→整页刷新保存的第3回合→直接标准点击回春术（无诊断滚动）→第4回合；按钮 bottom390/center358、tabsTop679、scrollY456，scrollWidth=documentWidth378。证据 `v4-combat-mobile-scroll-fixed.png`。不将失败的 v3 尝试标为修复成功。
2. **世界进度单调性防御。** 组件单测以角色 v1/world v4 → 动作角色 v2/world v3 复现旧实现将世界回退到 v3。已先红后绿：接受更新的个人档案，同时保留更高版本世界。这里是隔离的异步边界测试，不宣称生产实际出现过。
3. **日常奖励文字与剩余额度。** 固定“获得30币”在今日只剩10币额度时不准确。v3 改为最多10，额度用完与已领取分别显示真实状态，单测通过。
4. **读取长时间不结束。** 规则目录/榜单增加25秒中止与可重试提示；假时钟与可中止请求单测通过，未将这类模拟等同真实服务器故障。
5. **自动避让的触控回归。** v4 的键盘 focus 避让未区别指针聚焦，会在 pointerdown→pointerup 之间移动按钮，令真实点击落空。严格复现：撤离按钮完整可见 top630.85/bottom674.85、tabsTop679.2；点击后 scrollY8→327，按钮移动到311.85–355.85，等待3秒无确认弹窗。v6 改为 document 捕获输入方式，仅键盘焦点避让，保留遭遇恢复时的自动定位；原坐标单测先红后绿。**v6 真实 Nginx 复验通过**：同样 top630.85/bottom674.85、tabsTop679.2，标准点击立即打开确认框，scrollY40→40；Esc 隐藏游戏与弹窗并释放滚动，返回和取消后仍为第4回合。证据 `v6-pointer-boundary-confirm-mobile.png`、`v6-pointer-confirm-privacy-mobile.png`。
6. **只读断网提示歧义。** 旧读取错误复用了“不能确定操作是否完成”，即使用户没有提交动作。v6 把 overview/catalog/日榜/楼层榜的读取失败与 action 不确定回执分开，已有档案明确保留上次同步值；hook 红测已复现并修复。随后在真实 Firefox 仅对 browser a 的 overview 请求注入客户端读取失败，确认保留档案、显示“上次同步”而没有“确认上次操作”，恢复原 fetch 后刷新清除错误。证据 `v6-read-only-connectivity-desktop.png`；这是模拟客户端连接失败，不代表实际外网故障。
