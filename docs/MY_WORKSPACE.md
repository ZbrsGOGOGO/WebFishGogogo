# 我的工作台与工位搭子增强

站点所有者授权实施优化清单的 1、2、4、5、6 项；第 5 项采用「我的工作台」。不包含对战房间持久化、前端独立部署架构或容量压测体系。

## 我的工作台

现有 `/me` 与侧栏个人入口改名「我的工作台」，手机底栏仍显示「我的」。账户概览、办公币、成长积分与进度、期权持有者状态、常用工具和最近使用集中在资料编辑之前。新增默认文案使用成长、工作台、休息等中性表达；保留原成就头衔和用户主动佩戴的称号，不重命名资产协议或改变权益。

办公币余额来自既有账户钱包。新增 JWT 保护的 `GET /api/v1/farm/wallet-daily` 只读当前有效账号的 `wallet_ledger`，查询参数不能指定他人；按北京时间自然日 00:00—24:00 汇总正向入账与负向支出，使用十进制字符串保留 bigint 精度。入账包括实际记账的奖励与开户赠送，不包含未领取奖励；不伪造旧流水，不使用余额差推算收益。农场额外订单仍沿用原 05:00 业务日，两者明确区分。只在工作台前台定时/重新聚焦或手动刷新，失败显示待同步/旧值提示。

常用工具及最近使用只记录白名单内的入口路径，不保存查询参数、工具正文或浏览器全历史。按本机账号分别保存，最多各 8 条；支持取消收藏和清空最近使用，不公开或跨设备同步。

## 活跃计时

只有一个计时器，挂载在全部社区路由之上，覆盖独立 `/tools`、`/games` 与原主布局。游戏目录/排行榜不算游戏页面，小窗须真正运行且未遮罩/最小化才有游戏分类。普通游戏仍统计页面活跃，不声称全部游戏的内部暂停/完成状态都成为权威游玩记录。

路由、小窗和工作区遮罩变化先发暂停边界，避免把隐藏时段算入；下一心跳再恢复。重复边界不能让计时永久暂停。沿用服务端时钟、75 秒租约、三分钟无操作暂停、30 秒心跳、每日上限和多标签页不叠加等规则，不离线补发、不回填功能上线前或此前漏记时长。边界交接可能舍弃不足一个心跳的片段，不保证逐秒精确计费。

## 桌宠

身份切换只重置桌宠状态和编辑器，不重挂载整个路由。旧账号图片即时隔离，旧异步回调不能写入新身份；工具页已有输入/计时不因认证恢复而重置。依赖各业务自身的账号隔离仍保留。

自选图片支持 0.5–3 倍缩放、横纵移动、鼠标/触屏橡皮擦、撤销上次擦除和重置。只编辑已校验并缩绘的 256px 图，应用后重新生成 256/32px PNG；不是原分辨率修图、自动抠图或 AI 重绘。重调构图会重置擦除，取消不保存。喂食与摸头有不同状态标记，睡觉显示休息标记；安静和减少动画偏好不变。拖动靠边 32px 内吸附；方向键不吸附，保留精细移动。文本输入时暂时隐藏。

图片保存在原账号桌宠键后缀 `:images`，轻量偏好保留原键并注明分离存储。旧合并格式按首次修改惰性迁移，不在启动时批量改写其他账号。改名/位置/风格不重写图片；配额或权限失败明确提示，尽量恢复上次已保存图片。

导出 JSON 备份只包含桌宠设置及图片，不含账号、令牌或资产。导入限制体积、格式、版本与图片头/像素尺寸，并重新解码重绘，不信任备份内图片 URL。显示预览并确认后才覆盖当前档案，导入后默认关闭、位置归位。备份非加密，应妥善保管；用户可自行传至另一设备，不是服务器同步。确认清除仅删除当前账号的两个桌宠键。

## 发布与回滚

仅新增只读钱包汇总方法和前端，未改依赖、迁移、权限/赠送或运行配置。schema36 不变。部署仍按既有 API/Web 备份、恢复演练、隔离真实 PostgreSQL/浏览器验收及公网复核流程。

直接应用回滚基线为 `4840700`，保留数据库和所有本机存储。旧客户端不认识分离图片键，回滚后可能暂时显示内置形象；自选图片仍在本机，可再次升级或通过已导出的备份恢复，不删除图片键、不恢复旧数据库覆盖新数据。回滚不是重发赠送或真实成员授权。
