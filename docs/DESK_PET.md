# 工位搭子（免费、本机版）

入口 `/desk-pet`：桌面侧栏「工位搭子」，手机首页快捷入口。默认关闭，游客与登录成员均可主动领养，不要求期权持有者，不增加收费服务。

## 图片与外观

- 内置摸摸鱼、打工喵、发芽了三个代码绘制的矢量形象；用户也可选自己的 PNG、JPG、静态 WebP。
- 先检查文件大小（4 MiB）、图片头及尺寸（单边最多 4096、总像素最多 1600 万），再解码。拒绝 SVG、GIF、格式伪装、损坏、超大和动画 WebP。APNG 如可解码也只保留一帧，不保存动画。
- 本机 Canvas 缩绘到 256 × 256 透明画布，另生成 32 × 32 像素版；不拉伸原图，不自动抠图、生成角色或 AI 重绘。
- 原图贴纸、像素搭子、黑白纸片、拍立得四种效果。像素缩绘应用于自定义图片；内置形象保留矢量轮廓。风格为免费本机视觉效果，不冒充生成式 AI。
- 仅保存重新编码的 PNG，不保存原图、文件名、EXIF 等拍摄信息；输出及序列化存储均有大小上限，读取时再次白名单校验。不接受远程图片 URL。

## 交互及不打扰

点击摸头、免费喂食、睡觉/叫醒；鼠标/触屏拖动、方向键移动，位置按可用视口比例保存，缩放和旋转后限制在视口范围；Esc 收起。装扮页可召回、归位、关闭、调整名字/尺寸、切换安静模式。

默认专注避让：游戏、塔防、聊天室、私聊，以及纸上突围小窗打开时隐藏，可主动取消。隐藏标签页与过矮视口（例如手机键盘遮挡）不显示；认证和账号页面不显示。无声，不接管游戏快捷键，不创建后台循环；安静模式和系统减少动画偏好停用装饰动画。收起状态保留一个小型管理入口，关闭后不保留浮层。

复用既有摸鱼指数事件，仅在同一账号本次会话观察到境界上升时祝贺。不会从初次加载补发祝贺，不增加 XP、资产或管理权限，不替用户佩戴称号。普通真实用户操作仍按现有全站计时规则处理，桌宠不生成模拟输入。

## 保存与隐私边界

- localStorage 键 `webfish:desk-pet:v1:…`，游客与每个公开账号 ID 分隔；账号状态变化时重建上下文，旧图片立即从界面移除，未完成的导入不会落到新账号。
- 图片与设置只在当前浏览器保存，**不上传服务器或第三方、不跨设备同步**，也不显示在他人的主页。已有全站认证/心跳请求不属于桌宠上传。
- 同源标签页通过 storage 事件同步。容量不足/被禁用时显示未保存错误，保留当前预览，不谎称保存成功。
- 本机数据不是加密保险箱，不应导入敏感照片；公共设备应主动清除。退出账号隔离显示，但不会替所有设备删除本地档案。
- 清除须二次确认，只删除当前桌宠键，不执行 localStorage.clear，不影响游戏存档、其他用户或网站数据。浏览器自己清除网站数据也会删除桌宠，无法由服务端恢复。
