## 第一阶段已上线

- 统一清晰浅色 / 石墨深色、冰蓝强调、边框、层级与工作台壳层。桌面与手机保留快捷入口；默认侧目录分为今日、交流、游戏、工具、个人五组。
- 全部栏目可搜索，支持 Ctrl / ⌘ K；个人目录排序、隐藏和权限过滤沿用，调整过全列顺序的账号保留原顺序，不覆盖为新版默认值。
- 首页使用真实账户状态和模块入口。未加载或失败不伪造零余额/未读数；会话变更隔离旧请求，访客入口经登录门禁保留目的地。
- 可选本地 3D 工位主动启动后可调整视角和台灯，关闭释放资源；稳定后停止渲染，隐藏/离屏暂停，减少动效或 WebGL 不可用时降级。场景分包失败局部回退，不使整个首页不可用。
- 游戏大厅整理既有 **21 个入口**：全部、单机挑战、实时房间、角色与养成、本机练习及关键词搜索。显示设备、时长、登录、存档和奖励边界，六款公平挑战的信息来自公开服务端目录。
- 实时房间筛选显示 9 个对应入口，不把本地单机按钮当联机。纸上突围临时房、文字战线 v2 双人房与正式奖励日榜分别说明。小窗和工作便签遮罩生命周期保留。

账号、聊天、游戏路径、存档、后台权限、成绩结算、办公币与权益规则均未更改。本次不读取或回填新的协作反馈；不新增游戏、不接入暂停的掌心 AI 或支付服务。
