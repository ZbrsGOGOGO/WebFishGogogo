# 2026-09-08 全站真实浏览器系统验收

本文记录真实 Firefox 界面操作，不以单元测试数量代替功能验收。后端事务、权限竞态、奖励和真实 PostgreSQL 系统演练见 [系统主报告](SYSTEM_AUDIT_2026-09-08.md)。

## 环境、隔离与结论口径

- 本地访客验收：Firefox 154.0.1、geckodriver 0.37.1，读取生产 `0ec2d0b` 的完整静态产物。
- 登录后的系统验收：远端隔离容器内 Firefox 155.0.1、geckodriver 0.37.1，两个独立浏览器会话；普通成员 A/B、协作成员、审核员、管理员和停用成员均为合成账号。
- 浏览器访问 `http://127.0.0.1:4488`；HTTP/WS 只反代隔离 API，数据库为合成测试库，没有访问生产私信、用户附件或执行生产数据写入。
- SSH 转发被服务器拒绝后停止使用；最终浏览器和代理在隔离 Docker 网络内运行，通过正常 SSH 执行测试 RPC，没有开放公网端口或改变 SSH 权限。
- 基线 API/前端为 `0ec2d0b`。预览前端包含 `e776647` 的修复，预览验收期间 API 仍为基线；最终镜像验收单列于文末。
- 视口使用实际 `window.innerWidth` 复核：390 和 1440。Firefox 纵向滚动条会令 `documentElement.clientWidth` 分别为 378、1428；以 `scrollWidth <= clientWidth + 1` 检查页面横向溢出。
- 实际业务操作使用 WebDriver 原生点击、键盘、鼠标拖动和文件选择。页面脚本仅用于读取状态、滚动、定位元素；没有在页面伪造游戏成绩或绕过后端操作。
- “页面通过”仅说明该页完成渲染、相关加载和布局检查，不代表所有表单、异常分支及长周期结算都已测试。
- 生产关闭的内容写入、新闻管理、审核后台、找回密码、注销、社交核验和推荐奖励等功能，没有为了 UI 测试改变生产开关。隔离 API 的功能级验收和生产开关下的 UI 验收分开记载。

## 已纠正的测试工具假象

以下都不计为网站缺陷：

1. 农场主按钮在 WebDriver 默认滚动到底后被手机固定底栏截获。真实用户可继续滚动；改为先居中滚动后原生点击，实际收获通过。早期批处理曾在点击失败后继续记录；已改为遇错停止，并用 `BASELINE-FARM-CYCLE-CONFIRMED` 明确替代前两个中间记录。不得引用错误的早期“harvest-balance”截图宣称成功。
2. 榜单页使用 `div#community-main[tabindex=-1]`，没有 HTML `main` 标签。初版等待器强制要求 `main` 导致超时；复查页面与 API 都正常，跳转目标存在。改为页面真实标题/余额检查，不计作业务失败。
3. `<details>` 折叠区域内的 select 在几何读取中可出现矩形，但实际并未绘制。手机聊天室截图证实其没有覆盖发送按钮，不凭 DOM 几何误报。
4. 隐藏 file input 不能使用“清空后输入”辅助函数；直接使用规范文件 `sendKeys`，真实上传成功。
5. 同源游戏 iframe 内部分元素的默认 WebDriver click 未触发命中；改用父视口坐标的原生指针点击，重开干净页面完成遮司流程。没有把早期注入的诊断状态当成游戏成功证据。
