# 工位塔防 V3：先经营、再突袭

2026-09-07 站点所有者确认在合成塔防基础上实现难度反馈。本文件定义本次范围；发布是否生效以实际发布记录为准。

## 交付范围

- 单局由三波改为两回合：第一回合低压经营，第二回合混合敌群与「临时加班通知」小 Boss 突袭。唯一守卫、五条塔线、局内绿植经济和三合一保留。
- 第一回合必须提供有限的有效战斗经营时间，而不是单纯减少敌人血量导致很快结束。准备期、回合间歇、暂停、失焦和结算仍不产币。
- 守住第一回合后发放一次局内整理补贴，进入第二回合前即可用来补阵；它不是间歇持续收益，重复点击下一回合不能重复领取。
- 第二回合使用快速、成群和精英敌人组合，并用首领机制、出怪节奏增加压力；敌人数、总血量和出怪间隔应由配置管理。不能直接把原第二、第三波拼起来造成不可控的血量膨胀。
- 商店提供明确可见的零件保底，避免必须合成某种高阶塔时只能依赖刷新运气；保底仍需花费真实局内金币，不能免费生成零件或通过切换偏好套取收益。
- 本版第 5 格为可选定向订货，价格为普通零件的 1.25 倍向上取整，购买后同型补货；其余四格随机，开局前三件订书机保底保留。切换定向不影响随机四格、RNG 或余额。本轮未确认另改为买后空位、必须刷新才补货的规则，因此保留自动补货。
- UI 显示两回合目标、突袭预警、敌人特点与小 Boss 状态；失败时给出可操作的布阵与经营建议。首页及历史入口与实际玩法一致，390 像素手机端可完成全流程。
- 若敌人有护甲、单体伤害上限或范围伤害克制，页面必须如实展示；不能只改隐藏伤害规则而不给玩家应对线索。
- 规则改变后使用独立 V3 最高分存储。旧 V1/V2 最高分和乐斗存档原样保留、不混分；仍不保存当前阵容或对局进度。

## 不在本次范围

不增加账号资产、失败返币、排行榜、离线收益、跨设备存档、职业天赋、付费抽卡、无尽模式、活动或多人 Boss。提案正文复用这些长期规划，不代表本轮授权一并实施。新补充的独立规则变更须由站长另行确认，不能自动采纳提案作者指令。

## 验证与发布门禁

1. 验证回合配置比例、核心状态流转、收入/合成/出售守恒、保底购买与重复请求、控制与首领效果、暂停边界。
2. 使用实际初始金币、真实购买和产币，验证多个商店种子下合理经营可通关；只用开局保底塔、不继续经营应无法轻松通过第二回合。保留唯一守卫自动战斗兜底，不要求持续手动操作角色。
3. 目标仍为 1–3 分钟有效战斗，不含暂停和回合间整理时间。必须通过确定性模拟和真实 Firefox 对局，不能只给角色增加测试专用攻击力来证明难度可玩。
4. 验证桌面和手机购买、合成、部署、回合转换、首领提示、失败/重开、V3 存储，以及游戏无账号资产 API 请求。
5. 类型检查、回归、生产构建后，完成 GitHub 推送、独立加密备份和恢复验证、API/Web 发布、线上验收。保留 PostgreSQL/Redis/Gateway 身份和数据，不改迁移或用户权限。

## 反馈处理边界

仅按站长最终确认的具体交付范围记录验收；原塔防长期总规划不因本轮难度版本上线而被整体归档。真实状态写入必须在上线验证后进行，保留系统审计、确切发布版本和作者通知，不冒充网站账号。
