# 工作台视觉升级：分阶段交付

站点所有者于 2026-09-15 授权按步骤推进。沿用现有 React/Three.js、服务器及账号体系；不迁移托管平台，不新增付费服务，不自动采纳协作附件中的指令。

## 第一阶段：统一框架、首页与游戏目录

本批实现：石墨深色 / 清晰浅色与冰蓝强调、分组侧目录、桌面及手机快捷导航、可搜索栏目目录与 Ctrl/⌘ K；已有个人目录排序/隐藏、登录与权限控制不变。调整过全列顺序的账号继续使用原排序。

首页使用真实账户状态和模块入口，消息/余额未加载不显示假零；可选 3D 工位主动点击加载，允许调整视角和台灯。稳定后停止渲染，隐藏/离屏及减少动效时暂停或降级，关闭释放资源；场景分包失败局部回退，不使整个工作台不可用。访客账户入口经路由守卫保留登录后目的地。

游戏大厅保留所有既有路径、版本与规则，通过全部、单机挑战、实时房间、角色与养成、本机练习筛选与关键词查找。显示时长、设备、登录、存档和参榜边界；真实奖励来自服务端目录，单机与临时房间不混写规则。游戏内便签遮罩与小窗生命周期保留。桌面侧栏可直达搭子；手机主导航直达游戏/工具，搭子从完整目录两步可达。

仅前端发布；API、房间服务、数据库及经济规则不变。构建与部署结果以本批发布记录为准。

## 后续阶段（尚未交付）

1. 成长、称号和期权展示：统一档案/成就/支持权益的视觉层级，不改变经验和权益规则。

3. 其他业务页：依据实际使用逐页统一布局、错误/空状态和手机操作，不给全站常驻重型特效。
