# 《证道 · 命格模拟》导入说明

## 来源与范围

本游戏由用户提供的 `遮天三部曲之证道.zip` 导入。导入时记录的 SHA-256 为：

```text
34ec6528a54acb3e593c9b9a8d0deb9ea0d3723c2d795ad32cf457671f8415a3
```

压缩包共 194 个条目。站点只保留经过审查的源码入口与 8 个浏览器脚本：

- `packages/frontend/public/games/zhengdao/index.html`
- `packages/frontend/public/games/zhengdao/js/01-data.js` 至 `08-app.js`

备份文件、调试/探针脚本、Windows 批处理、构建辅助文件、编辑器元数据及包含动态执行代码的合并发布页均未导入。游戏作为独立静态文档从 `/games/zhengdao/` 打开，不接入社区后端结算。

## 运行与数据边界

- 游戏无需登录，刷新、断网后仍可运行已加载的单局。
- 命格录与成就只写当前浏览器的 `momo.zhengdao.life-history.v1` 和 `momo.zhengdao.achievements.v1`。
- 没有成绩上传、全站排行榜、账号资产奖励或服务端存档。
- 导入版本不发起 `fetch`、XHR、WebSocket 或第三方网络请求，也不使用 `eval` 或 `new Function`。
- 页面提供返回摸摸公司游戏中心的入口，并明确提示“本机存档”。

## 发布边界

原压缩包没有附带许可证或权利声明，且内容包含第三方作品名称、设定和专有名词。代码可以在当前工作区继续联调，但面向公众部署前必须由站点所有者确认拥有相应授权；否则应先替换为原创世界观、文案和命名。这个检查是内容权利门禁，不影响账号、好友、聊天室或其他原创小游戏发布。

## 验收

发布前至少验证：静态入口和 8 个脚本均返回成功；游戏能完成一次开局、抉择、重开与本机记录；浏览器网络面板没有游戏 API 或第三方请求；清理站点数据后本机记录确实消失。
