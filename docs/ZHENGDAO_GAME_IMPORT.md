# 《遮司》命格模拟导入说明

## 来源与范围

本游戏由用户提供的 `遮天三部曲之证道.zip` 导入。导入时记录的 SHA-256 为：

```text
34ec6528a54acb3e593c9b9a8d0deb9ea0d3723c2d795ad32cf457671f8415a3
```

压缩包共 194 个条目。站点只保留经过审查的源码入口与 8 个浏览器脚本：

- `packages/frontend/public/games/zhengdao/index.html`
- `packages/frontend/public/games/zhengdao/js/01-data.js` 至 `08-app.js`

备份文件、调试/探针脚本、Windows 批处理、构建辅助文件、编辑器元数据及包含动态执行代码的合并发布页均未导入。独立静态文档仍可从 `/games/zhengdao/` 打开，自身不直接访问社区后端；站点内的 `/games/zhesi` React 包装页负责账号赛局与服务端结算。

## 运行与数据边界

- 游戏无需登录，刷新、断网后仍可运行已加载的单局。
- 命格录与成就只写当前浏览器的 `momo.zhesi.life-history.v1` 和 `momo.zhesi.achievements.v1`。
- 独立静态页没有成绩上传、全站排行榜、账号资产奖励或服务端存档。
- 登录用户经 `/games/zhesi` React 包装页游玩时，只上传由服务端重新校验的最佳战力摘要；不上传完整人生事件、抉择文本或本机命格录。
- 导入版本不发起 `fetch`、XHR、WebSocket 或第三方网络请求，也不使用 `eval` 或 `new Function`。
- 页面提供返回摸摸公司游戏中心的入口，并明确提示“本机存档”。

## 发布边界

原压缩包没有附带许可证或权利声明，且内容包含第三方作品名称、设定和专有名词。本次生产的 `PUBLIC_GAME_CLEARANCE_REFERENCE` 配置项已填写非占位值，并由站点所有者明确指示部署；这只表示工程预检门禁通过，不等同于对授权真实性或第三方权利作出法律判断。站点所有者仍应持续确认授权，不能确认时应替换为原创世界观、文案和命名。

## 验收

本次自动化与无凭据公网烟测已确认静态入口、8 个脚本、React 包装页和游客排行榜合约可达。完整验收仍应使用真实浏览器完成一次开局、抉择、重开与本机记录；确认网络面板没有游戏 API 或第三方请求；确认清理站点数据后本机记录消失；并使用专用测试账号验证游客不提交成绩、登录状态仅提交并展示服务端校验后的最佳战力摘要。
