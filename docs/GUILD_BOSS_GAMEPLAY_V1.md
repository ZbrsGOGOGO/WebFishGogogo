# 帮派首领玩法 v1

## 定位

“季度截止线”是第一条真正多人共享进度的 PVE 内容。它不要求成员同时在线，但同一帮派的成员会共同削减同一条服务端血量，并可刷新查看当日贡献榜。

## 玩家流程

1. 职场 Lv.15 后加入或创建帮派。
2. 在乐斗的“帮派”页查看当日首领、共享血量和贡献榜。
3. 每位成员每天有 1 次有效攻击，消耗 10 体力。
4. 攻击固定获得 120 办公币、25 职场经验和 25 帮派活跃；暴击只影响共同进度，不放大个人货币奖励。
5. 全帮将血量降到 0 后显示“今日已击败”，次日 05:00 生成新一期。

## 数值规则

- 首领血量：`900 + 成员数 × 450 + 项目室等级 × 350`。
- 基础伤害：`300 + 职场等级 × 30 + 项目室等级 × 80`。
- 每次攻击额外增加 0～160 点服务端随机伤害。
- 暴击率 12%，暴击造成 150% 伤害。
- 最后一击只记录实际扣除的血量，贡献不会溢出。
- 小帮派也能获得完整个人参与奖励；集体击败用于共同目标，不把货币集中给最后一击或伤害第一名。

## 服务端约束

- 同一 `guild_id + service_date` 只有一条首领记录。
- 同一 `run_id + user_id` 只有一条贡献记录。
- 幂等键防止网络重试造成重复扣体力、重复伤害或重复奖励。
- 体力、首领血量、贡献、经验、办公币、奖励凭证在同一个数据库事务中提交。
- 服务端按帮派记录加锁，多名成员同时攻击时不会丢失伤害或把血量扣成负数。
- 客户端不能提交伤害、暴击、奖励或首领血量。

## 后续版本

- 公会阶段奖励与全员领取记录。
- 基于职业 PVE 技能的首领机制，而不是单纯提高数值。
- 三人异步小队副本、周常首领和可恢复的副本快照。
- Redis 推送首领血量变化；当前 v1 通过每次操作后的权威快照同步。
