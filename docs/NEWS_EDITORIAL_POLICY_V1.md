# 热点新闻编辑与来源策略 v1.0

## 1. 首版边界

热点新闻是“可追溯的外部资讯摘要”，不是新闻抓取器或全文镜像站。首版只允许三类来源：

1. 本站自行发布且拥有完整权利的公告；
2. 政府部门、事业单位、标准组织等官方公开页面；
3. 已取得明确转载或摘要授权，且授权仍在有效期内的来源。

系统不自动抓取网页，不复制第三方正文、图片、音视频或付费内容，不根据点击量伪造“热度”。没有可核验来源和授权状态的内容不能发布。

## 2. 每条资讯的必填信息

- 来源名称与来源类型；
- 原文 HTTPS 链接；
- 原文标题、原文发布时间；
- 由本站编辑撰写的 50～300 字摘要；
- 职业标签与主题标签；
- 授权状态及仅管理员可见的凭据索引；
- 编辑、复核人、版本、发布时间和最后更正时间。

公开 API 只返回摘要、来源名称、原文链接和公开时间，不返回内部授权凭据、编辑邮箱、个人联系方式或后台账号主键。

## 3. 工作流

状态固定为 `draft → pending_review → published`。来源授权已撤销、原文删除或内容有误时，执行 `withdrawn` 或发布更正说明；所有决定写管理员审计日志。

- 编辑可创建和修改草稿，但不能批准本人提交的内容；
- 管理员先验证来源与授权，再批准发布；
- 已发布版本不可原地覆盖，修订后重新进入复核；
- 下线后列表不再出现，直接访问只返回最小更正/下线说明；
- 不允许通过公开 API 创建来源、发布资讯或修改授权状态。

## 4. 排序和个性化

默认展示非个性化的“最新发布”列表。个性化必须由用户主动打开，只能使用用户明确选择的乐斗职业、主题偏好和负反馈；不得使用真实身份核验材料、邮箱、设备、精确位置或跨站跟踪。

排序可综合发布时间、来源可信等级、职业匹配和用户负反馈。页面不展示未经审计的阅读量、虚假在线数、虚假评论数或“全网第一”等结论。

## 5. 讨论与外链

新闻评论首版关闭。“发起讨论”只会进入经验交流的新帖编辑页，并预填来源链接；帖子仍经过实名门槛和内容审核。外链使用新窗口、安全 `rel` 属性并明确标注“前往原文”。

## 6. 发布闸门

生产默认关闭：

- `FEATURE_COMMUNITY_NEWS_ENABLED=false`：关闭全部新闻公开 API；
- `FEATURE_NEWS_ADMIN_ENABLED=false`：关闭编辑与发布操作；
- `VITE_COMMUNITY_NEWS_ENABLED=false`：隐藏新闻导航和页面入口。

正式开启前必须至少有一个已审计管理员、一个有效来源、一条完整的授权/官方来源记录，并完成真实 PostgreSQL 迁移、权限、撤回和缓存失效测试。
