# 农场玩法说明 · 单机首发版

农场采用“领取资源 → 选择空地 → 种植 → 离线生长 → 手动收获 → 推进成长”的轻量循环。首发版只做个人农场，不包含好友偷菜、玩家交易、付费抽奖或可提现资产。

## 一、基础循环

1. 首次进入自动建立个人农场，并一次性发放 4 水滴、4 颗小麦种子、2 颗草莓种子和 1 颗咖啡种子。
2. 默认开放 4 块土地。点击空地，再选择满足等级和资源条件的作物。
3. 种植时同步扣除水滴和对应种子；同一块地同一时间只能种一种作物。
4. 成熟时间由服务器记录。关闭页面、退出登录或服务器正常运行期间离线，都不会让生长倒退。
5. 成熟后由玩家手动收获。作物奖励、农场经验和每日任务进度在同一次操作中结算。
6. 每种作物收获时返还 1 颗同类种子，种子循环不会因正常收获而中断；继续种植所需的水滴主要来自每日签到。

## 三、成长与跨系统联动

- 农场等级和全站等级分开计算：农场经验负责解锁农场内容，全站 EXP 进入统一账号成长。
- 农场达到 Lv.2 后可种咖啡；达到 Lv.5 后开放第 5 块土地。
- 每日签到获得 5 水滴，为下一轮种植补充资源。
- 收获会产生可信活动记录，并推进农场类每日任务。
- 咖啡可补充精力；精力可以用于午休斗技场，因此形成“签到补水 → 农场收获 → 恢复精力 → 单人竞技”的首发闭环。

## 四、数据与防重复规则

- 土地、资源、作物成熟时间和奖励均以后端数据为准，客户端只负责展示和发起操作。
- 种植、收获和奖励使用幂等键及资产流水；网络重试不会重复扣资源或重复发奖。
- 收获前由服务器再次检查成熟时间，修改浏览器时间不能提前收获。
- 玩家只能操作自己的土地，资源和活动记录也按账号隔离。

## 五、首发边界

单机首发版优先保证循环清楚、操作稳定和资产安全。好友系统、访问他人农场、装饰摆放、订单、更多作物、天气和自动化生产可作为后续扩展，但不会改变“服务器时间 + 统一资产流水 + 幂等奖励”的底层规则。
