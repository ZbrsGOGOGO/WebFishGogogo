# 九层妖塔：物资申领与绑定资源

规则版本：2026-09-11。本文说明实现规则与兼容边界，不代替实际部署、生产验收或反馈回填记录；线上版本以[文档索引](README.md)中的最新发布记录为准。

## 集中入口

进入 `/games/demon-tower`，选择「物资申领」。页面顶部同时展示灵石、残魂和全站办公币，避免将不同资源混为一种余额。人物与探索等其他页签保留余额快捷栏，可直接跳到申领入口；成长工坊不再重复铺开同一份兑换清单。

| 分类 | 内容 | 可直接打开的站内路径 |
| --- | --- | --- |
| 物资库 | 灵石补给、临时药丸、疗伤与基础材料 | `/games/demon-tower?tab=shop&supply=supplies` |
| 残魂秘市 | 新增定额申领与保留的传统兑换 | `/games/demon-tower?tab=shop&supply=market` |
| 增益与符文 | 今日加成、永久加成、符文库存与装配 | `/games/demon-tower?tab=shop&supply=effects` |
| 收支记录 | 最近灵石收支、新申领与符文使用 | `/games/demon-tower?tab=shop&supply=ledger` |

页签与分类保存在 URL 中，支持刷新与浏览器前进/后退；切换分类关闭未确认的申领单。申领使用确认弹窗，展示币种、单价、数量、总价与剩余额度。当前处于战斗、自动探索、维护、请求提交或结果待确认状态时，只能查看，不能手动购买或装配符文。

## 三种资源各自独立

- **灵石**：新增的账号绑定塔内资源，初始为 0，通过新规则下实际完成的玩法取得。没有登录赠送、历史补发、充值、转账或办公币兑换入口。
- **妖塔残魂**：沿用原存档的 `materials.soul`，不清空、不重命名成灵石，不重新发放。保留原有掉落、升级和兑换用途。
- **办公币**：沿用全站钱包与账本，本模块只展示其余额。物资申领不扣办公币、不向其他玩家转账；原妖塔办公币奖励与上限没有被灵石规则替换。

新材料、符文和永久加成均绑定当前账号。真实付费、支付回调、玩家交易和付费战力不在本模块范围内。

## 灵石取得与限额

| 实际完成的来源 | 灵石奖励 |
| --- | --- |
| 普通探索战斗胜利 | 每次随机 2–4 |
| 普通探索的非战斗奇遇 | 每次随机 5–15 |
| 小秘境通关 | 每次随机 20–40 |
| 世界首领有效贡献 | 每次 `floor(服务器实际扣除的首领生命 / 2)` |

每日灵石总收入最多 **200**，其中世界首领最多 **100**，首领额度包含在总额内，不额外叠加。余额最多 1,000,000。达到收入或库存上限时不再增加，页面与回执说明原因；花掉灵石不会重新腾出当天收入额度。

首领奖励只使用共享世界行锁内确认的实际有效伤害，过量伤害不计、同一请求重放不重复领取。周常讨伐、小队、论道和普通修炼没有因此新增灵石奖励，原有奖励仍按各自规则结算。新灵石随机流与既有战斗和装备随机流分开，不因增加灵石奖励而改变旧掉落序列。

## 申领清单

以下补给确认后立即结算并生效，不先存入可囤积的药品背包；符文箱产出的绑定符文例外，会进入符文库存等待装配。

| 物资 | 单价 | 限额 | 效果与限制 |
| --- | --- | --- | --- |
| 小份体力包 | 20 灵石 | 每日 5 份 | 恢复 3 点体力 |
| 大份体力包 | 45 灵石 | 每日 2 份 | 恢复 8 点体力 |
| 五维临时药丸 | 每项 15 灵石 | 每维每日 3 份 | 对应属性每份 +5，当天单维最多 +15 |
| 疗伤符 | 30 灵石 | 每日 2 份 | 一次恢复全部生命；每次只能申领 1 份，满血不可使用 |
| 基础材料包 | 25 灵石 | 每日 3 份 | 随机获得玄铁砂 ×3 或通道线索 ×3 |
| 五维永久丹 | 每项 30 残魂 | 每维累计 5 份 | 对应属性每份永久 +1，单维最多 +5 |
| 精级武器箱 | **8 残魂** | **每周 1 份** | 周折扣补给，Lv16 起；随机获得当前已达装备等级的精级武器 |
| 绑定符文箱 | 40 残魂 | 每周 1 份 | 随机获得 2 枚绑定符文；可能同名，每种库存最多 99 |

体力仍然是 **上限 100、每 3 分钟恢复 1 点**，不是每天重置到满。普通探索仍消耗 5 点，修炼 6 点，休整 5 点，世界首领挑战 10 点。体力包需要足够的完整恢复空间；不吞掉溢出部分后照常扣款。购买材料包或符文箱前，服务器检查任一可能奖励是否会超库存上限，可能溢出时整单拒绝。

「疗伤符」提供主动恢复生命的选择，不引入新的持续伤势惩罚，也不替代原有自然回血与消耗体力的休整。原休整仍恢复最大生命的 50%。

精级箱的 **8 是残魂价格，不是八周时长**。它只出精级、每周限一次，不取代原 12 残魂武器箱，也不推进或消耗原武器箱的第十箱保底；获得已拥有武器时沿用同名品质经验规则。

## 原残魂玩法完整保留

传统兑换集中放在「残魂秘市」下方，但成本、物品池与保底继续独立计算：

- 12 残魂武器箱，Lv16 起，每第十箱至少灵级。
- 10 残魂技能箱，获得技能并附送残页 ×1。
- 35 残魂悟性丹，获得当前等级可学习、尚未拥有的技能；已经学全时不扣款。
- 30 残页自选符合等级的仙级技能。
- 原 40 残魂升星符与免费熟练度成长仍保留；升星失败不降星。
- 装备升阶所需材料、暂存品质经验回收和既有残魂来源不变。

残魂并非只来自普通击怪：初始角色赠送、探索与秘境胜利、有效世界首领贡献、小队胜利及主动回收暂存品质经验各有既有规则。新商店使用同一个真实库存，不能把它们作为新账户重新结算。

## 临时加成、永久加成与符文

五维为力量、速度、敏捷、防御和幸运。永久丹独立保存在经济状态中，不直接增加自由属性点；免费洗点只重新分配原自由点，永久加成不丢失，也不能被洗成额外自由点。

临时药效用于个人探索与首领战，不进入论道或小队的角色快照；永久加成在各玩法中保留。幸运药丸沿用幸运在暴击、相关技能和掉落触发率中的作用，不修改探索奇遇的分支概率。

日限、今日收入与临时药效按**北京时间 00:00**切换；周限按**周一 00:00**切换。灵石余额、残魂、符文和永久加成不会随日限清空，永久上限也不会每周重置。

进行中的战斗使用开战快照：跨过午夜不会中途削弱敌我属性或改写已有战斗生命上限。战斗外展示及后续新战斗不再包含到期药效。新规则上线前已开始、没有经济版本标记的旧探索战斗不追发灵石；原战斗奖励和角色进度保留。

武器品质达到 +3 / +6 / +9 时分别开放 1 / 2 / 3 个词条槽。使用一枚符文可填入空槽，或明确选择替换一个已有词条；同一武器不能重复同名词条，旧词条不返还。装配前再次确认目标武器和替换内容，不自动购买、不自动消耗库存。

## 数据与操作安全

- 服务器根据商品 ID 计算价格、效果、资格和限额，不接受客户端传入价格、余额、收益或他人的账号 ID。
- 余额扣减、效果、次数、角色版本与动作回执在同一事务内保存；相同请求编号重试不重复扣款，不同并发请求需通过角色版本校验。
- 金额或限额不足、容量不足、参数越界及失败事务都不应留下半笔扣款。出现「确认上次操作」时，先确认原回执，不反复新建购买请求。
- GET 只返回投影，不因查看商店初始化入账或永久写回存档。旧角色在合法写操作中前向补入初始为零的经济状态。
- 页面收支登记最多保留最近 **30 条**，记录新灵石收支、新定额申领与符文使用。它不补录传统残魂兑换、其他残魂来源或历史收入，不能冒充全站钱包的完整账本。

## 发布与回滚边界

本实现沿用 schema36，在原妖塔角色私有 JSON 中增加版本化经济状态，无新增 SQL 表或生产迁移。本功能不自动修改真实账号权限、原支持期限或赠送记录；站长另行明确授权的成员操作按独立审计记录处理。

关闭扩展玩法开关时，新申领入口与动作、新灵石收入以及新战斗和掉落计算中的临时药效暂停；灵石余额、符文库存和永久加成保留，进行中战斗仍保留开战快照。关闭开关不会删除临时药效记录，原北京时间到期时间仍然适用；重新开启不会延长药效。

**没有 SQL 迁移不等于旧应用可以安全写新存档。** 回滚到不认识经济状态的旧应用前，应停止新版 API 接收并排空在途写入，再暂停妖塔整体与自动探索，保留全部新 JSON、道具、余额、修订和审计数据。不能清除经济字段、运行数据库 DOWN，或恢复旧数据库覆盖发布后的玩家进度。

本轮回滚基线为已验收的 `2111004be1cc407b95cc9859afc43ac8fb10ece5`。回滚使用本轮完整环境备份，仅暂停妖塔及自动探索；原已开启的投稿和审核继续保留。优先以前向兼容修复恢复妖塔，不以关闭全部社区功能掩盖兼容问题。生产具体版本、镜像、备份及验收结果由对应正式发布记录单独说明。
