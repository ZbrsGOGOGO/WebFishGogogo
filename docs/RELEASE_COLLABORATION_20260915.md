## 交付内容

### 妖塔：明确每次出发发生了什么

原规则本来就是 **70% 遭遇妖物、15% 宝匣、15% 机缘**，普通出发均消耗 5 体力。非战斗结果正常直接结算；本轮没有证据证明服务器先独立扣体力再漏做探索，不能把正常宝匣/机缘说成失败后退款。实际缺陷是界面只显示部分事件、响应丢失或返回页面后缺少持久化出发说明，玩家难以确认扣费对应的结果。

- 出发在原角色、随机状态、额度、奖励和命令回执的同一事务保存结构化明细：三结果分类、楼层、来源、实际体力/探索符消耗、已获经验/材料/灵石及实际授予办公币。
- Overview 只读恢复本账号最近一次成功的普通/耗符出发；同时间记录按角色版本确定顺序。刷新、返回以及后续攻击后仍可查看完整已存事件。
- 遭遇回执与之后的战斗终局奖励明确分开，回看不重复结算。历史回执仅保存真实文字和已存办公币记录，不凭字符串补造数值、退款或补发。
- 未确认最新档案时禁止新动作，未知结果保留原 UUID 重试；同步、切号和同账号重新登录后废弃上一会话的迟到响应。未公开原始存档、随机种子或他人回执。

原概率、5 体力、1 张探索符、每日额度、掉落、升级及钱包结算规则不变。操作编号/角色版本并发只成功一次，事务失败时角色、随机推进、奖励、额度和回执一起回滚。详细使用方式见 [玩家指南](DEMON_TOWER_PLAYER_GUIDE.md)。

### 异步猜画：免费不限每日次数与一人一票

按最新评论的“无需奖励机制”完成评分；**评分不增加积分、办公币或其他奖励**，没有新增付费功能。

- 移除猜画每日 3 次创作及保存/提交/猜题的旧每日动作限制，也不消耗其他工作台动作的每日总计。保留总体 100ms、各类绘画动作 700ms 短节流，单草稿、服务端 2 分钟截止及已保存笔画自动提交。
- 既有 56 题及作者最近 12 个题目避重保留。只对已证明未发布且笔画为空的过期终态做有界历史清理，保留近期题目；不清理真实画作或永久幂等回执。
- 非作者提交至少一次真实猜题后，可评 1–5 整数分，不必猜中；一人一票可修改，均分/人数/本人评分在猜题框下展示。作者不能自评，未猜中答案和其他评分者内部编号不返回客户端。
- active 状态、双向拉黑、隐藏、写开关、会话和原 UUID 边界保持服务端校验。注销明确清理本人在他人画中的 ratings/guesses，保留其他参与者数据与未知 JSON 扩展。
- 存储保护：个人 1000、全站 5000 个有效作品，隐藏作品仍计入；每次写入画作状态最多 256000 字节、每画最多 1000 个参与账号、每人最多猜 5 次。达到容量不伪装为“每日次数用完”，全站容量检查串行化。

原猜中者 10、画主 5 社交积分保留，不加评分奖励。仅新猜画积分入队每账号每北京时间自然日合计最多 100（已领取亦计入），未领取队列满 200 条时不再生成新的猜画奖励；不删除/倒扣旧奖励，不改变其他玩法原入队规则。原每日领取 100、50 分换券的限制保持。接收者顺序 advisory 锁与用户 KEY SHARE / NO KEY UPDATE、档案和帖子锁序实际验证，无目标用户外键假设或反工作室保证。详细规则见 [公司工作台](OFFICE_HUB_RULES_20260909.md)。
