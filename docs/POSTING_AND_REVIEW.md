# 投稿与站长审核

2026-09-10 站点所有者确认：正常登录账号均可提交帖子，审核通过后才向其他成员展示。

- 入口：经验交流 → 帖子与问答 →「发布帖子」。空列表另有「写第一篇帖子」，入口不因只读或未核验而消失；真正不能写入时明确说明原因。
- 投稿不再要求额外社交核验，但必须是 active 账号；登录、封禁、停用、作者归属、版本冲突和服务端内容写入开关仍生效。不修改用户核验字段或赋予成员审核权限。
- 支持保存草稿、提交审核、撤回待审及修订。所有帖子（包括管理员帖子）均人工审核；未批准的修订不会替换已批准正文。此变更不取消其他模块原有的核验规则。
- 审核入口：帖子页「帖子审核」、页头或全部栏目中的「审核台」。仅已有 admin/moderator 角色能进入，API 会再次鉴权；开发协作权限不等于审核权限。zbrs 沿用原 admin 角色，不重复授权。
- 审核操作沿用通过、限制展示、隐藏、恢复；必须填写原因，保留版本与审计记录。“隐藏”作用于帖子的展示状态，不冒充新增的“驳回修订”操作。
- 开启生产环境的 `FEATURE_COMMUNITY_CONTENT_WRITES_ENABLED` 与 `FEATURE_COMMUNITY_MODERATION_ENABLED`，Compose 分别映射为 API 的 `FEATURE_CONTENT_WRITES_ENABLED`、`FEATURE_MODERATION_OPERATIONS_ENABLED`；审核入口还是构建时开关，因此必须重建镜像，不能只改浏览器显示。
- 不开启注册、不自动授予核验、不接入付费服务；不新增表，不执行生产迁移。真实发布结果及回滚版本以本次正式发布记录为准。
