# 排行榜、聊天室与玩家文案规则 v1

- 适用范围：俄罗斯方块、坦克大战、办公室乐斗、固定聊天室
- 目标规模：4000 注册用户、1000 同时在线
- 规则版本：`arcade-score-v1`、`office-power-v2`

## 1. 玩家界面原则

普通玩家页面只描述玩法、状态和可执行动作，不展示“服务端档案、发布闸门、审核版本、内部接口、审计种子”等实现或运营提示。管理与审核信息只在获得对应权限的后台页面出现。

游客只可使用工具和两款小游戏。农场、乐斗、经验交流、投喂、邀请、我的主页和好友均要求有效登录账号。

## 2. 聊天室

- 每个固定房间只保留最近 200 条消息，而不是每次只返回 200 条但永久保存全部历史。
- 新消息成功写入的同一事务内删除该房间第 201 条及更早消息。
- 应用启动时再次清理历史存量，确保升级前遗留数据也收敛到 200 条。
- 历史接口单次最多返回 200 条；默认返回最近 50 条。
- 房间按序号独立保留，删除消息后不回退序号，保证实时订阅游标单调递增。

## 3. 小游戏排行榜

只保留两款小游戏：俄罗斯方块与坦克大战。游客可直接玩和查看榜单；登录玩家开局时创建一次短期游戏记录，结束时提交成绩，只有个人最佳成绩进入榜单。

### 3.1 俄罗斯方块

- 排名字段：游戏内得分，从高到低。
- 相同得分：先达到该成绩者在前；若时间也相同，按公开玩家 ID 稳定排序。
- 可信边界：开局与结束必须对应同一条未过期记录；校验用时、消行数、等级与分数的合理范围。
- 合法范围：最多 500 行、Lv.1～60、最高 500 万分；高等级四消和软/硬降得分均预留合理空间。

### 3.2 坦克大战

- 每击败 1 个敌人得 100 分，共 3 个敌人，最高 300 分。
- 胜利必须对应击败 3 个敌人；得分必须严格等于击败数乘 100。
- 排序和同分规则与俄罗斯方块一致。

## 4. 乐斗战力与排行榜

五维属性为活力 `HP`、执行 `ATK`、抗压 `DEF`、反应 `SPD`、洞察 `LUK`。展示战力统一为：

```text
round(HP × 0.34 + ATK × 3.20 + DEF × 2.50 + SPD × 1.80 + LUK × 1.20)
```

PVE 战力读取角色等级、当前六件装备的完整属性与 PVE 技能等级。

PVP 战力读取相同角色等级和六件装备，但装备强化带来的属性增量只计 60%，再叠加 PVP 技能。基础装备属性不折损，避免低等级玩家因进入 PVP 被二次削弱。

榜单包括：

1. PVE 全职业总榜。
2. PVP 全职业总榜。
3. 程序员、产品经理、测试、销售员、人力资源管理五个职业的 PVE 分榜。
4. 上述五个职业的 PVP 分榜。

排序依次比较战力、等级、胜场，仍相同时按公开玩家 ID 稳定排序。每次最多读取 100 名，页面默认读取前 50 名；排行榜不返回邮箱、账号名、内部用户 ID 或装备隐私数据。

## 5. 容量与后续平衡

- 小游戏最佳成绩使用“游戏 + 用户”复合主键，榜单使用“游戏、得分、达成时间”索引，避免按每局历史全表排名。
- 乐斗当前 4000 用户规模可实时计算；达到 1 万用户或榜单读取 p95 超过 300ms 时，改为按资产版本增量更新的战力快照表，并缓存各榜前 100 名 30～60 秒。
- 每周检查五职业同培养区间的 PVP 胜率，目标 48%～52%；任意职业长期超出 46%～54% 时只调整技能系数，不改已有装备资产。
- 小游戏只记录个人最佳成绩，异常成绩拒绝进入榜单；后续增加回放摘要或输入事件校验时保持现有榜单规则版本不变，新规则使用新版本字段。
