## 现网适配与安全边界

- 源码存档键绑定本站 `publicId`，避免同一浏览器切换账号后串档。
- 原源码客户端“办公币”改名为玩法内“战利券”，不读写或冒充本站统一钱包。
- PVP 按钮进入本站已有服务端房间；排行榜按钮进入保留的 V4 服务端验真赛季。
- iframe 为本站同源静态页面，CSP 禁止联网、表单、对象、媒体及第三方资源，只允许本站脚本/样式；Nginx 只允许该精确文档被本站同源框架加载。
- `postMessage` 只接受同源且来自目标 iframe 的消息，导航路径限制在文字塔防子路由。
