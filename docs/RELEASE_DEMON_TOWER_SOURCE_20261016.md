## 4. 原子命令、幂等和限额

- 单份解码存档最大 512 KiB；每账号北京时间自然日最多 720 次存档、累计 64 MiB 解码存档写入。
- 每账号每日最多 120 次共享世界动作，合并计算 `damage`、`channel`、`clue`；伤害、建设量和累计次数由服务端封顶并以事务、幂等回执约束。玩法引擎仍来自隔离浏览器源码，这三种动作是**有界客户端申报**，服务端不重演整场随机战斗或探索，因此只进入无网站奖励的共享展示，不能兑换网站办公币、成就或权益。
- 三类共享动作都携带 `requestId`、`expectedVersion` 和动作后的 `saveData`。服务端在同一事务内更新档案、日额度、世界、贡献和命令回执；探索线索因此能随账号云档和世界回执在刷新后恢复。
- 相同 `requestId` 返回原回执，不二次执行。个人档案版本冲突返回确定结果，客户端先重载再决定新动作。
- 传输结果不确定时，客户端只能用同一请求号确认；仍无确定回执则冻结写入并要求整页重载，不得重新掷随机玩法或生成新请求号重试同一动作。
- 仅 `PUT /source/progress` 与 `POST /source/world/damage|channel|clue` 四个写入口使用精确的 Nginx `1200k` / Nest JSON `1200kb` 包络；解码后的 `saveData` 仍严格限制为 512 KiB，其他妖塔路由不得继承大包络。

## 6. 旧版当日奖励收口

切换前先避开北京时间跨日窗口，并查询所有历史贡献日是否仍有未结算记录；若有，必须先由仍在运行的旧 worker 补到稳定，不能用最终日脚本重放历史日期。随后停止旧 API（同时停止旧奖励 worker），等待进程优雅退出以排空在途写入，再重新查询确认历史无遗漏、切换日伤害快照不再变化。只有在旧写入已经物理停止后，才可使用日期绑定、非 HTTP 的一次性脚本结算当前切换日，并证明合格冠军恰好一笔奖项、奖励凭证和钱包账本；无合格记录则保存零待结算证据。完成这些门禁后才能迁移并开放源码版。该动作尚未执行，结果为 **TBD**；不得先结算后继续接受旧伤害，也不得跨日执行。

## 8. 直接回滚

回滚是 **API + Web 应用回切**，不是数据库回退：

1. 排空在途写入并停止新 API/Web；保留 schema43、五张源码表、全部新档及旧数据。
2. **禁止**运行 DOWN、删除新表、恢复切换前数据库、重建数据卷或把旧存档写入新表。
3. 旧 API 不会清理五张源码表。回切前必须设置 `FEATURE_ACCOUNT_DELETION_ENABLED=false`；启动后同时验证前端注销入口不可见/不可用，以及注销 API 被服务端拒绝。
4. 只有删除入口和 API 两项都关闭，才可开放旧应用；否则保持维护状态并恢复候选应用。
5. 回滚期间源码版写入暂停；恢复候选版本后继续读取保留的新档。不得套用早期妖塔兼容桥、旧奖励重放或 Web-only 回退流程。
