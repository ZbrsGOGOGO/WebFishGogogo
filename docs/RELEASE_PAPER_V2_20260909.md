## 本轮实现

本轮将 Paper 联机小窗升级为原版纸笔画风场景和人物，不再使用简单方盒角色或空旷放大地板；原单机玩法和地形行为保持不变。

- 直接复用已在本站本地托管的原版场景、手绘人物以及步枪、霰弹枪、左轮、狙击枪、武士刀五套模型和动作表现。支持原版切枪、瞄准、换弹及近战表现；每把武器独立弹匣、备用弹药和动作时序由服务器管理，不接受客户端上报伤害、位置或成绩。
- 保留原脚手架、建筑、楼梯、栈桥、吊机等地标原位，扩展到 **96 × 102** 范围，并增加有交错掩体的四侧外环。联机移除原地板与四面旧边界，再添加与共享碰撞数据一一对应的 **33 个可见扩建盒子**，不添加只有服务器知道的隐形扩建墙。
- 共享地图元数据从实际原版 `buildArena()` 确定性提取；移动碰撞、立足顶面与射线遮挡分别核对。导航使用分段碰撞检查及真实楼梯踏面连接，不把跨楼层直线标记当作可行走路径。详见 [地图来源和几何核验](PAPER_ARENA_MAP_V2.md)。
- 联机协议为 **v2**，地图版本为 **`office-expanded-v2`**。沿用 4–8 人红蓝房间、房主可设密码、20–100 击败目标、AI 补位和服务器随机复活；客户端只发送按键、视角与动作意图。
- 保持低调小窗及输入隔离，暂停、失焦、退出房间等行为由页面与连接生命周期处理。退出时释放本实例渲染资源，不销毁原单机共用的模型缓存；无外站 iframe、游戏 CDN 或新增音频依赖。
- 修复真实 Firefox 已处于 pointer lock 时再次 `setPointerCapture` 抛出 `InvalidStateError` 的输入路径；增加捕获条件与竞态保护，并补上全局触控释放，防止指针在按钮外释放后仍保留动作。新增3项前端回归，最终不可变镜像中的实际双浏览器重验通过。

### 明确边界

- 当前没有服务器补给互动，原补给标记在联机隐藏；六个木栅栏在联机保持静态，不伪造仅本地可见的破坏效果。原纸飞机、部分细栏杆和斜撑保持非交互装饰。
- 射线使用原模型 world AABB 的保守近似，不声称非盒状水箱、吊钩等已实现逐三角形或孔洞精确命中。
- 本轮不新增办公币、排行榜奖励、付费功能或管理权限，不修改开发反馈状态，也不重新发放 VIP。其他游戏、账号、聊天、公司及收藏功能不属于本轮新增范围。
- API 重启会结束现有内存中的 Paper 临时房间。该房间状态不是持久存档；不以重启删除真实玩家资产或数据库记录。
