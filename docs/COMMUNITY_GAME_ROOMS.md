# 小游戏、房间与排行榜

## 入口与产品边界

- `/games` 为轻量协作工作台，区分单机挑战与玩家建房；提供贪食蛇、俄罗斯方块、坦克大战、遮司短局、你画我猜、谁是卧底。
- `/games/rooms` 列出等待房间，房主可设置密码；留空则公开加入，新界面不再使用邀请码。开始后不能加入、离开后不能回到同一局。每人最多同时参加一局（包含新增轨道难题）。旧私密房保持私密，不会自动公开。
- `/leaderboards` 为侧边栏的独立排行榜专区，含办公币余额榜与六款游戏日榜；另新增独立[轨道难题生存榜](COMMUNITY_RAIL_ROOMS.md)，游戏内有对应日榜快捷入口。
- 经典三款多人模式是“同样初始条件、各自棋盘、限时竞分”，不是共享地图互相攻击。遮司短局是独立、固定初始数值的回合试炼，不读取或改变原命格录长期存档。
- 你画我猜支持轮流画图、实时猜词；谁是卧底支持描述线索和投票。单人模式有明确标注的系统练习搭档，不能把它们当真人。普通房间 2–8 人，卧底至少 3 人。
- 原 `/games/snake`、`/games/tetris`、`/games/tank`、`/games/zhesi` 自由练习和长期存档继续保留。原 Arcade API 最佳成绩与新的每日奖励榜分开，不能把旧客户端自报成绩迁入发币榜。

## 计分和经济

- 服务器生成随机条件、推进时钟、校验动作和计算最终成绩。客户端只提交动作，不提交分数、余额、奖励或时间；同一动作 ID 和序号重复发送不会再次执行。
- 一局最长不超过 180 秒；无任何有效操作的整局、零分、系统搭档和中途退出者不获得榜单成绩。
- 单机挑战与玩家房间共用该游戏的日榜，每人每天每款只保留最高成绩；不同游戏不混排。
- 成绩日期按**服务器实际结算时的北京时间日历日**，00:00 分榜。停机或跨午夜后才处理的终局归入处理当日，不回写已经发奖的历史日榜。
- 同分优先保留先取得的成绩，再按稳定账号标识排序。低分或同分不会覆盖本人先前的最好成绩和取得时间。
- 次日北京时间 00:05 起自动结算：每款第一名奖励 **100 办公币**，六款最多 **600/人/日**。停机后补发；仅活跃账户可获奖。
- 奖励占位必须严格 INSERT；奖项、统一资产奖励记录、钱包流水、通知同一事务提交。唯一键和稳定奖励来源共同防止重复发币，失败留待下一次重试。
- 办公币榜展示活跃用户的**当前余额**和我的排名，前 50 名可见；消费会改变排名。只读展示，不初始化钱包，也不按财富排名发奖。接口须登录，不返回邮箱、内部用户 ID 或权限字段。

## 房间、隐私与操作

- 房间详情只向真实成员返回；管理员身份不是查看他人谜底的通行证。大厅不返回邀请码、私密游戏状态、随机种子或用户隐私字段。
- 作画者只在自己轮次看到谜底；猜词者不获得谜底。卧底进行时只看到自己的词，终局才公开角色。
- 房间密码只保存带密钥预哈希后的 bcrypt 校验值，4–64 个 Unicode 字符；猜密持久限速，等待阶段房主可修改或清空。房间等待 1 小时过期，参与者可主动退出。房主退出等待房间后，按加入顺序转移房主。
- 新建限制 24 小时内 60 局；每局每人最多 1,800 个接受动作、每秒最多 12 个，内核还有按游戏设置的频率、轮次和文本/画布限额。
- 浏览器动作串行、有序；不明网络结果使用原动作 ID 重试。切账号或离开页面会丢弃旧响应与待发送操作，不把 A 的数据交给 B。
- 运行中约 300 毫秒请求一次、等待中减频；请求不重叠，后台页进一步降频。独立游戏入口 IP 限流预算，避免同一办公网络的游戏轮询耗尽普通账号/聊天 API 额度。
- 社区工作台默认静音、低饱和度；便签遮罩收起画面但不卸载房间、不暂停服务器计时。本地经典练习遮罩后暂停，恢复画面不自动继续；原遮司同源 iframe 支持 Esc 桥接，不改静态资源及存档。它不是浏览记录或网络访问的隐藏工具。
- 聊天室保留原实时连接、消息权限和历史数据；界面默认最近 50 条，可加载更早消息。本次不新增删除聊天记录的计划。

## 发布与回退

迁移 `1700000000027` 仅增加 `play_rooms`、`play_room_members`、`play_commands`、`play_daily_scores`、`play_daily_awards`，不更改旧钱包、旧游戏存档或聊天室消息。功能只装配在社区根模块，生产写入和自动结算沿用社区写总闸。

迁移前必须完成新鲜加密备份、异机校验、完整恢复和隔离真实 PostgreSQL 演练。应用回退只回退 API/Web，保留所有新表和已发放资产；生产不能执行本迁移的 down。容量测试未完成前不宣称支持大规模同时在线。

密码在增量迁移 `1700000000029` 接入。**回退到不识别密码的旧 API 时，必须先关闭 `FEATURE_COMMUNITY_WRITES_ENABLED`，保持只读维护，不能开放旧入房写接口**；详细规则和回退边界见[轨道难题与密码](COMMUNITY_RAIL_ROOMS.md)。
