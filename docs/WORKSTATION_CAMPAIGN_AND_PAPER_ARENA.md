# 工位正式任务与纸上红蓝协作

## 工位正式任务

正式入口 `/tower-defense`、独立正式榜 `/tower-defense/leaderboard`；原离线练习保留在 `/tower-defense/practice`。两者共享确定性游戏引擎，但练习最高分不会导入正式排行榜，也不能兑换真实办公币。

需要同时启用 `FEATURE_COMMUNITY_WRITES_ENABLED`、`FEATURE_WORKSTATION_CAMPAIGN_ENABLED` 和前端 `VITE_WORKSTATION_CAMPAIGN_ENABLED`。新开关默认关闭；关闭写开关后，服务端不会继续推进或结算，已保存记录仍可读取。

已实现的正式玩法：

- 六章剧情、六十波上限的无尽模式、独立极限资格模式。极限首轮要求零漏怪并部署三星主力，不影响普通剧情入门。
- 四种职业的主动/被动、三系免费重分配天赋、八档个人升职，六到九个实际可部署工位。
- 两件/三件同类塔羁绊、连胜加成、守卫实际耐久和挡伤、受损绿植停产及局内修复。
- 五秒准备与 GO 跳过、合成进度、购物稀有闪光、移动福袋、周末补给与休息事件。
- 存档续局、当前局的离线回放、阵型蓝图、近期战报、个人成就和文字/截图分享。阵型蓝图只是记录，不会免费生成下一局防御塔。
- 收藏外观通过 OfficeHub 获取和实际展示，只改变颜色，不提供付费或隐藏战力。

### 权威与奖励

`/api/v1/games/workstation` 只接受严格白名单命令、局 ID 和版本号。服务器生成随机种子并保存完整状态；浏览器不能提交分数、余额、种子、时间跨度、波次结果或任意状态。

引擎每 280ms 一个逻辑 tick；同步仅按服务器已经流逝的时间推进。一次最多回放 1200 个 tick，保留余时和待回放进度。关闭网页只回放当前有限对局，不自动开新局；暂停局不继续刷收益。后台先推进到真实时间再应用命令，过期版本和结束局操作会被拒绝。

真实办公币采用现有钱包账本，不与局内 G 混同：

| 项目 | 边界 |
| --- | --- |
| 单局办公币 | 至多 40 |
| 每日对局办公币 | 合计至多 80 |
| 败局 | 服务器确认的基础收益的 30% |
| 空局/未形成有效击败 | 不发币，不发成长经验 |
| 职位成长 | 每日前 12 个已结算对局内发放，单局至多 120 经验 |
| 每模式昨日冠军 | 12 办公币，次日凌晨后结算；剧情/无尽/极限独立 |

对局结算事务锁顺序为用户、工位档案、对局；钱包账本有唯一幂等键。职位经验、战报、真实钱包与 OfficeHub 塔防贡献在同一事务中提交，任一环节失败全部回滚。每日冠军采用日期+模式唯一认领，多个 API 副本不会重复发奖。

新增迁移 `1700000000033` 仅增加工位档案、对局和冠军审计表。应用回滚应保留这些表及存档，不应重建数据库或执行生产向下迁移。

### 常规回归与真实 PostgreSQL

```sh
npm run build:shared
npm run test --workspace @stealth-reader/frontend -- src/features/workstation-tower-defense
npm run test --workspace @stealth-reader/backend -- tower-defense.spec.ts
```

`tower-defense.postgres.spec.ts` 是额外的真实 PostgreSQL 集成套件，不把 pg-mem 结果当成实际数据库并发验证。它必须显式提供 `TEST_PG_URL` 和 `TEST_PG_ALLOW_INTEGRATION=true`，数据库名称必须匹配 `webfish_test_*`，且只允许测试邮箱；无 URL 时明确跳过。只创建和清理本套件的随机测试用户，不执行 TRUNCATE 或数据库删除。

套件检查并行开局、同版本重复购买、并行结算、下游失败整笔回滚及双副本冠军幂等。其终局 fixture 由测试直接写入服务器拥有的隔离数据库，仅用于事务验证，不代表存在客户端写终局状态的接口。

## 纸上红蓝协作前端

大厅 `/games/ballpoint-breach/arena`，对局 `/games/ballpoint-breach/arena/:roomId`。需要前端 `VITE_PAPER_ARENA_ENABLED`，服务器还有独立对应开关。保留原单机代码、材质许可证和单机暂停体验；联机是独立入口与运行实例。

创建房间可选 4–8 席位、20–100 击败目标、可选密码；不使用邀请码。玩家换队仅限等待阶段，空位和短时掉线由服务器 AI 接替。服务器复制位置、生命、弹药、命中、战果和复活时钟；前端只发移动与瞄准/开火/装填意图。

小窗使用原纸笔描边与排线材质，默认静音，可扩大、最小化或遮盖为工作便签。小窗缩小/遮盖会卸载 3D 画面并清零输入，但服务器对局不暂停；路由离开会关闭实时连接。窗口失焦、隐藏、别的小游戏取得输入、图形上下文丢失时也清零输入。

WS 票据通过认证 HTTP 获取，只发于 WebSocket 首帧，不置于 URL、日志或持久存储。前端绑定登录会话代次，只在认证完成后发输入；不发送客户端位置、分数或奖励。固定 25Hz 控制输入，服务器快照仅做画面插值，不做前端战斗结算。

当前联机房间是短会话：单局最长 15 分钟、空房过期、重启可能中断，暂不发放办公币或修改正式排行榜。页面已明确这些边界；不能把联机遮盖描述为暂停。

### 验证范围

```sh
npm run test --workspace @stealth-reader/frontend -- src/features/games/paper-arena
npm run typecheck --workspace @stealth-reader/frontend
```

前端测试覆盖连接认证/重连/旧会话隔离、命令白名单、地图/材质生命周期、房间配置、原生输入规则、最小化/遮盖、图形中断清零等。另以真实 Firefox/WebGL 检查了桌面和 390px 小窗渲染、原生键盘经 WS 到共享引擎的移动。

上述本地浏览器检查使用隔离共享引擎夹具，不等于真实后台双账号验收或生产验收。最终发布须另外核对真实登录、密码建房、双用户通信和生产开关，以实际发布记录为准。
