# 《赵云与阿斗》全属性总表

> 游戏为 **2 合 1 合成升级**玩法。
> - 基础小兵：刀 / 弓 / 枪 / 骑（满级 Lv5）。
> - 武将最高等级 5 级（紫 / 蓝武将满级更低，见下表）。
> - 攻速上限 **7.65**。
> - 攻击类型分【单体 / 贯穿直线 / 范围 AOE】，范围以棋盘格子数计。
