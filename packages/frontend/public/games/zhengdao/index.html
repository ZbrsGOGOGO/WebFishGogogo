设 定 · 玩 法 图 鉴

遮天世界浩瀚、命数繁复——此页为你梳理全部设定，随手查阅，不必再为看不懂而困。

① 一句话玩法

你诞生于遮天世界，资质 / 种族 / 体质 / 先天寿元（及身份、出生地）随机而定、不可更改。点「受命此生」从凡人起步，一路破秘境修行，目标——证道称帝，乃至长生成仙。走完一生后可「再投一世」，命格另定。

② 你的命格（初始四属性）

资质（悟性）：决定突破成功率与悟道速度；体质：天生根骨，部分体质带诅咒或禁忌（如源术诅咒、特殊帝躯）；先天寿元：与生俱来的寿命，破秘境可延寿；种族：人族 / 古族等，影响兵器天赋、战力上限与出生地。

③ 境界体系（五大秘境）

凡人 → 轮海 → 道宫 → 四极 → 化龙（九变·脱胎换骨）→ 仙台（六层天：半步大能→…→大圣）→ 准帝（九重天）→ 大帝（证道称帝）→ 红尘仙（长生不朽）。每破一秘境都可能引动天劫，渡劫失败或折寿、或身死道消。

④ 证道之道（修行主路线）

入仙台后择一道而终：修炼 / 源天师 / 功德 / 人欲 / 仙厨。各道加成不同，部分道途有专属奇遇与终试（如人欲道）。选哪条道，决定了你余生的风景与凶险。

⑤ 修行取向（道宫 / 四极 / 化龙 三次抉择）

这三大秘境入口各触发一次取向抉择：厚积·修身（稳、凶险少）/ 外求·修法（机缘盛、凶险随福）/ 炼心·修心（抗心魔、最平稳）。取舍贯穿你此后余生。

⑥ 奇遇（命运抉择）

道宫之后偶发八类奇遇（古矿、前辈、古战场、妖丹、帝蜕、尊伦、仙路、星矿……）。手动模式下会弹「结果卡」让你亲自拍板；自动模式由天意代择。一世最多十次。

⑦ 人欲道 · 情缘与终试（专属机制）

择【人欲证道】者，仙台后须结一段情缘——无情缘则证道之门永闭，绝无大帝之望。冲击大帝的那一刻必触发「情关」：杀妻证道 / 斩断情根 / 博爱一生 / 双帝同证——亲手改写你证道之机与帝路结局。

⑧ 手动 / 自动 模式

底部「抉择」可随时切换。手动：方向 / 取向 / 奇遇 / 情关等命运抉择由你亲自点选；自动：天意随机代择（金色 ⚙ 日志为证）。

⑨ 命格录 与 回看

每世结束自动存入「📜 命格录」。点某世的「回看」，可重览这一世的完整一生——从出生到坐化 / 证道 / 成仙的事件时间线，尽数铺陈。

⑩ 结局档位（成帝 / 成仙）

评级从「凡」到「红尘过客」……直至 大帝（证道称帝）与 红尘仙（长生不朽）。成帝已极难，成仙更是万古一人——二者皆为命数与抉择共同写就。

⑪ 命运难度 与 养成模式

开局可选命运难易：🧊 如履薄冰（凶险，成帝极难）/ 🔥 爽玩（宽厚，成帝≈20%·成仙≈5%）/ 🌱 养成（温和慢养，复用爽玩宽厚曲线，主打慢节奏 + 高互动）。点「🌱 养成」会自动切到最慢常速 + 手动，并在每个大境界入口弹出「修行侧重」抉择——你亲手把心力倾注到 ⚔战力 / ✨悟性 / ❤道心 / 🌟机缘 / ⏳寿元 五维之一，侧重累加贯穿余生，界面实时呈现养成 HUD：战力·悟性提突破率、道心降死亡率、机缘增造化、寿元直接延寿。数值可见可养，真正亲手带大这一世。

⑫ 隐藏彩蛋

某些特殊道途与抉择会触发隐藏剧情（如诡异红毛、祖师复活、肚饿真君、红尘仙的异界幻觉……）。此处不剧透，留待你亲手撞见。
