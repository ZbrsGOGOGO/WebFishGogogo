## 本站适配

玩法、数值、装备、功法与界面主体来自该 ZIP。本站只做运行和安全适配：

1. 在无同源权限的浏览器沙箱中运行源码，禁止源码直接联网、读取网站 Cookie/令牌或操作父页面。
2. 通过临时随机标识和固定白名单消息桥接账号存档、世界进度、真实好友与排行榜。
3. 增加读取先于写入、版本校验、失败回滚、请求幂等和输入范围校验；塔内办公币与网站办公币完全独立。
4. 修复高层首领基础数值缺失、HTML 转义、内联事件与内容安全策略冲突、通道解锁时序及异步行动失败后状态未完整回滚。
5. 增加深色主题、窄屏布局、键盘焦点和减少动画适配；移除附件中不适用于本站的外部注入、测试后台与本地备份说明。

旧版 React 妖塔仍只作为发布回滚历史保留，不在当前生产路由、接口或排行榜中运行，也不与本源码版数据融合。
