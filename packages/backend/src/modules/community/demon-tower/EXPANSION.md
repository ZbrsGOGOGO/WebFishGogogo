# 免费妖塔扩展交付合同

## 开关与存档

- 服务端 `FEATURE_DEMON_TOWER_EXPANSION_ENABLED`、前端 `VITE_DEMON_TOWER_EXPANSION_ENABLED` 均默认关闭；原妖塔开关、统一维护写闸、VIP 自动探索边界不变。
- 新字段为已有私有 JSON 存档的 `expansion.version=1`，只在没有进行中战斗的显式写动作适配。GET 不写迁移、RNG、材料或权益。旧战斗保持自身 `rulesVersion`；新战斗另有 `expansionVersion=1`。
- 旧副本逐份转品质经验，按境界自动兑现；旧强化/星级不降低。首次适配已满足用户点击的升级时，不再偷偷付费升下一阶。新重复与暂存经验都不清空。
- 增量迁移 0034 仅新增 `demon_tower_squads`，不更新现有世界血池/等级/资产，不执行 down。应用回退到不认识此扩展的旧 API 前，应关闭妖塔写入及自动任务；保留数据库及新存档，不试图反向变换资产。

## 论道与小队

- 论道是自愿公开、异步PvP，不冒称实时房间。读取对方当前服务端配装快照，仅更新发起者积分/荣誉/SP；不扣对方血量/资源，不推进共同世界。最多30回合、每天5名不同对手，退出重入不重送初始SP。五系各三招，严格1终极/2主动/1被动与前置技能。
- 荣誉仅兑换外观徽记/称号、精魄、少量材料；无办公币或付费货币。
- 小队为2—4人自愿准备的独立回合副本。每人准备扣本人3体力、占当日最多3次之一，并冻结配装及生命快照；队友不能代准备。全员明确准备后开启，任意成员推进一回合，最多20回合。
- 实际战斗包含召唤助灵、群攻武器清怪、低速目标冲锋/高防队友分摊、狂暴全体攻击、治疗与单次队友复活。只伤队伍快照，不改另一玩家账号HP。
- 房间24小时过期，建房每24小时最多5次。胜利后每人通过本人幂等动作领奖一次；未准备/外人不领，不发可刷取的办公币。
- 所有动作沿用账号锁、世界锁、CAS、完整请求哈希、不可变回执、统一写闸和日切回滚。小队另锁房间行。等待世界锁后重新读取个人版本，防注销匿名化被旧快照写回。
- `/v1/games/demon-tower/social` 必须登录，仅投影自愿公开对手和公开等待/本人房间；不输出私有build、账号内部ID、RNG、哈希、密码或邮箱。
- `cleanupDemonTowerExpansionUser(manager,userId,publicId)` 供软注销事务调用，移除该用户小队快照、重新分配房主、匿名化他人论道历史，不删除队友资产。根账户生命周期负责删除注销者自身档案。
