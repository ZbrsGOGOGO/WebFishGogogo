# 妖塔免费成长首期：v0.6/v0.7 合并定稿

2026-09-09。此文件记录本轮实际规则与未做子项，不能将原提案整体标记为完成。

## 规则

- 稳定ID不变：20武器、16技能；保留固定主手1/辅助法器1、主动3/被动2。武器获取率不等于武器出手率；本期未改为全武器随机出场或全技能无槽位触发。
- 武器获取等级精1/灵16/仙31/神46，装备等级精16/灵31/仙46/神61。技能获取和学习等级凡1/精16/灵31/仙46。先过滤获取资格再按稀有度40/30/20/10归一、再按原始单品权重抽样。概率是“已出物品且确定武器/技能种类、无保底干预”后的条件概率，不是每次探索的掉率。
- 普通探索胜利和原有非战斗宝箱/灵脉事件共用同一真实来源池；没有虚构小秘境/周常Boss/商店。正常是否掉落仍受幸运与混元幡影响。每4次可掉落结算的物品保底保留，武器/技能交替；**收集偏好改为抽中的稀有度内优先未拥有，而非保证每4次必出全目录任意未拥有**，否则稀有度权重形同虚设。
- 达到Lv16开始计“灵以上未得”探索结算，20次未得则下次保底；Lv31开始计“仙以上未得”，50次未得则下次保底。未达资格不增加计数；仙优先于灵，两者一起被足够稀有的实物掉落重置。若所选物品种类尚没有合资格的保底物品，切到另一个种类（例Lv16灵武器可得而灵技能不可得），绝不抽空。共享Boss不算此探索计数。
- 新手五武器是“训练赠送可装备例外”，不是新增五件白板装备。老存档已拥有的武器/技能永久保留使用资格；资格绑定已持有稳定ID，重复品仍是同ID副本，不存在售卖/转赠资格。新获得未拥有物品没有例外。现有+N/材料升阶成功率、耗材与动态升阶等级仍保留，不自动消费旧副本，不改造成品质经验。
- 武器星级独立于+N，从1到5星；每次普通攻击行动主手和已装法器各+1熟练度，不要求命中，多段/AOE/反击不重复计数。回春附带一次普攻也只计一次。每星需当前星×15，升星清零，合计150个普攻行动满星；每星使主手普通攻击及其连击伤害+10%，辅助法器星级培养后可在改主手时使用，不额外放大被动掉率。失败/撤离不回收已完成行动的熟练度，防止断线回滚刷请求；没有升星符、概率降星、充值或新通用货币。
- 玩家明确选择一次心性主维，获得对应的第一个永久命格；Lv1/16/31/46/61/76/91/106依次补齐8个，后续按目录顺序选尚未拥有者。旧角色没有伪造问答，也需点选；高等级选择后一次补齐合法数量。命格属性只加到派生值，不属于洗点可返还点数，不送治疗或材料，不占16技能槽。
- 回春术：同一玩家回合先治疗、再普通攻击一次，只消耗一次动作与一次冷却。裂地斩：有效直接命中非Boss目标有20%概率震慑一次，仍有自身减速。
- 疾如雷电：普攻最多一次30%速度伤害追击，不能递归触发自身或再调用行动。兵器通神只放大普通攻击/对应连击，不放大技能、反伤、毒伤。身轻如燕增加直接攻击暴击率5个百分点；钢筋铁骨减少直接伤害10%；金刚不坏开局加DEF护盾。
- 装死：本场首次致命伤保留1HP，先于已布置的续命丹心消耗；以后遇致命伤才消耗续命丹心，两种效果各一次。毒伤也走这个优先级，多段/后续攻击不会因此停止。
- 气运一击：非Boss目标8%压至1HP（保留护盾，不触发额外吸血/眩晕），否则原幸运随机伤害。共享Boss严格免疫压血，战报提示，仅有正常伤害；不改变世界血池/榜单贡献校验。
- VIP只负责委托选择合法动作；手动和委托共用引擎与上述规则。20探索/260步骤/15分钟/每步2秒、低血停止、每日200办公币与2000动作、Stop/到期/注销/改密/日界线和幂等事务边界不变，不自动买、升阶或打Boss。

## 存档与发布/回滚

无SQL迁移、新表、重建世界或全量覆盖。schemaVersion仍为1，新增可选growth.rulesVersion=2和武器星级/例外字段；新版本读取时严格只接受已支持的规则版本。

GET只投影，不写数据库、不挑选命格、不推进RNG。无成长字段的旧存档在第一次合法的战斗外写动作上做一次加法适配，保留原ID/+N/副本、种子/计数、材料/经验/基础属性/未花点数、原4次保底和世界进度；新20/50计数从0开始，不虚构过去抽取。

已有普通战斗rulesVersion缺省为旧规则1，完成/撤离前不适配成长，治疗仍只治疗，原战斗不插入新随机调用、星级和命格。结束后的下一个非战斗动作才启用新成长；自动任务也走同一路径，不能中途切规则。新战斗保存rulesVersion=2及当场命格快照、装死消耗标记，可跨worker重启继续。规则升级过程中不改变任务/角色版本控制和单步回执。

**回滚注意：727576b结构上可读取额外JSON字段，但旧引擎不会执行新战斗/成长规则。不得以“JSON向后兼容”为理由带写回滚。若回退727，须先关闭妖塔写与托管、等待在途动作安全完成，备份并保留新存档，旧版本只能只读展示；恢复可写应使用理解新字段的修复前向版本。** 不能用清空growth或回灌全站旧数据库来抹掉玩家进度。
